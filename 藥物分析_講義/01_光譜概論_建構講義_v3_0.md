# 光譜概論｜從檢品資訊到訊號判讀

^sp-c-home

這章先練「要知道什麼，該選哪一類方法」。同一顆錠劑可以問成分、含量、微量雜質、分子結構或原晶型；不同問題需要保留不同資訊。第一輪先走完四站和一個基本例，再學量與單位、訊號來源及國考比較。

[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-home|開啟複習導航：閉卷重建與斷線救援]]。

閱讀順序：大循環 → EX01 → 最小語言 → 六個存檔點 → 十二條 L → 方法與操作 → 紙筆 C1–C5 → 27 題來源題。

## Part 0｜全章大循環

^sp-c-macro

**先定問題 → 準備與測量 → 讀訊號 → 核對結論。**四站是分析者整理資訊的流程；條件合格就交出答案，不必每次都繞回重測。

### M01｜先定問題

^sp-c-m01

問身分、含量、結構、微量雜質，還是原晶型？

**交出：**目的、代表性檢品、狀態與方法路徑。

### M02｜準備與測量

^sp-c-m02

決定製樣、分離、交互作用與需要的條件。

**交出：**可產生所需資訊的測量條件；L1、L3–L10，L12 先規劃。

### M03｜讀訊號

^sp-c-m03

辨識座標、單位、參考，做必要換算與處理。

**交出：**波長／波數、吸收／強度、核訊號、m/z、繞射圖樣；L2 換算。

### M04｜核對結論

^sp-c-m04

用適當參考、校正及品質條件，核對推論。

**交出：**附條件的答案；L11 核對性能，晶型需固態證據。

| 不符情況 | 修正動作與回站 |
|---|---|
|目的／檢品／方法不合|重選目的、代表性檢品或路徑 → M01。|
|製樣／激發／參考條件不合|修正實際製備、作用或背景 → M02。|
|座標／單位／訊號處理錯|修正量與讀法 → M03。|
|結論超出證據／判準不合|查參考與校正 → M04；需新資料才回相應上游。|

### 完整基本例｜同一顆錠劑，先問原晶型

^sp-c-basic

**自編 EX01。**同一成分可以在固體中有不同的分子排列，這叫 Polymorphism（多形性）。現在只問：「這顆錠劑的原晶型較符合參考 A 還是 B？」

已知 A、B 在保留固態的 Infrared spectroscopy（紅外光譜，IR）中有可區分的特徵。甲方案保留固體、使用已確認不改樣的相同製備；得到的多個特徵與 B 相符。乙方案先完全溶解，再做 Diffusion-ordered spectroscopy（擴散排序光譜，DOSY；本例為溶液核磁共振的擴散分析）。選哪個方案能支持原晶型比較？

| 走到哪一站 | 把已知資訊接成理由 |
|---|---|
| M01 先定問題 | 問原固態排列；不是問溶液有幾個成分。 |
| M02 準備與測量 | 甲保留原狀態，且此配置能區分兩個參考；乙已完全溶解。 |
| M03 讀訊號 | 讀甲的多個固態 IR 特徵；題給它們與參考 B 相符。 |
| M04 核對結論 | 在已給的製樣與比較條件下選甲，支持較符合 B；乙的溶液擴散資訊不直接保留原晶格。 |

**完整答案：選甲，並在這個例子的條件下判較符合 B。**理由不是「IR 永遠最好」，而是甲保留要問的資訊，且已有可辨識的參考特徵。尚未取得含量資料，就不由此算含量；若實際樣品是混晶、含水或製樣改變，應回相應的站核對。

**現在用自己的話說一次：**要問什麼 → 是否保留目標資訊 → 真正讀到什麼 → 能支持什麼結論。

### 符號與單位：量的是哪一種量？

^sp-c-symbols

| 符號／名詞 | 中文意思 | 常用單位 | 一眼防錯 |
|---|---|---|---|
| Wavelength（波長），λ | 相鄰同相位位置的距離 | nm、μm、m | 是長度，不是頻率 |
| Frequency（頻率），ν | 每秒振動次數 | Hz＝s⁻¹ | 希臘字母 ν，不是速度 v |
| Wavenumber（波數），$\tilde\nu$ | 每單位長度的波數 | cm⁻¹ | 不是「每秒」；不是 Hz |
| v | 所在介質中的傳播速度 | m/s | v 與希臘 ν 不同 |
| λ₀ | 真空波長 | nm／m，依式子統一 | E=hc/λ₀ 要用真空波長 |
| C | 校正曲線的濃度 | 依模型，如 mol/L | 不與光速 c 混用 |
| c | 真空光速 | m/s | 約 $3\times10^8$ |
| h | Planck constant（普朗克常數） | J·s | 能量×時間，不是 J/s |
| E | 一顆光子的能量 | J／photon 所表示的單顆能量 | 別與一整束總能量混同 |
| T、A | Transmittance（透光率）、Absorbance（吸光度） | 無量綱 | 本章只用讀數概念，詳細定量留 UV 章 |
| m/z | Mass-to-charge ratio（質荷比） | 質譜慣用的 m/z 數值 | 不能不看電荷就當中性分子量 |
| ppb、pg、M | 十億分率、皮克、mol/L | 比例、質量、濃度 | 三者不能只看指數互換 |

**最少數學：**倒數、比例、$10^a/10^b=10^{a-b}$。不知道一個數代表哪種量時，先停下看單位。

### 波段定位：先記順序，再記本題需要的錨點

^sp-c-bands

**波長由長到短：射頻 → 微波 → IR → 可見 → UV → X-ray → γ-ray；每光子能量大致往反方向增加。**部分類別尤其 X／γ 的命名也涉及來源，界線可重疊。

| 區域 | 來源採用的波長位置（nm） | 本章要用的辨識 |
|---|---|---|
| X-ray | 約 0.01–10 | 0.5 nm 選 X-ray；XRD 可比較晶格 |
| 真空 UV／更短 UV | 舊稿約 10–200 | 屬 UV 大範圍的一部分；一般儀器下限不是統一 200 |
| 題本 UV 區 | 200–380 | 220、250 nm 均為 UV |
| visible（可見光） | 380–780 | 500 nm；紫端較短、紅端較長 |
| NIR（近紅外） | 780–2500 | 2200 nm；裸錠與水分等應用 |
| 中紅外 | 舊稿採 2500–50,000 | 振動特徵；分區慣例各教材可能不同 |
| 遠紅外 | 舊稿採 50,000–1,000,000 | 低頻振動／轉動等，依系統而定 |
| 微波 | 舊稿約 10⁶–10⁹ | 可作分子轉動光譜 |
| 射頻／NMR | 實際頻率依核種與磁場 | 本題四選項中 NMR 使用波長最長 |

本表是來源定位索引，不是每種光源的發射規格。**190 nm 的氘燈題不能因為題本把 UV 表從 200 nm 開始就判不能用。**宇宙射線主要是粒子，已從電磁波分區表移出（S7）。

### L1｜波長、頻率與傳播速度

^sp-c-l1

**先問：**同一介質中 λ 變為 3 倍，ν 變多少？

**掛載：**M02 提供「傳播速度與波長」→ 本條 L → M03 使用「相應頻率及改變方向」。

**短鏈：**固定速度 → 波長變長 → 每秒波數變少 → 頻率降低。

**白話理由：**一秒走過的距離固定，每個波若占更長距離，一秒只能通過較少個波。先固定速度，才有波長與頻率反向的關係。

**立即用一次：**同一介質中，波長由 250 nm 變成 500 nm，是兩倍；頻率便為原本的一半。

**條件／易錯：**固定傳播速度；換介質不可硬套反比。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**同樣速度前進的一串波，波與波間隔拉長，固定位置每秒收到的波會變少。

先固定傳播速度，再看「一個波多長」與「每秒過幾個」：

$$\text{每秒走的距離}=\text{每秒波數}\times\text{每個波長度}$$
$$v=\nu\lambda;\qquad \text{真空中 }c=\nu\lambda_0$$

所以速度固定時，$\nu=v/\lambda$。**λ ×2 → ν ÷2**，不是兩者一起增加。

若光進入另一介質，頻率保持，由傳播速度與波長改變；不能把所有介質的 λ 都直接塞入 $E=hc/\lambda$。本章一般波段題用真空／近似空氣波長。

小檢查：同介質 λ 從 250 變 500 nm，ν 變為原本一半。[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-ni1|回 Ni 重建]]

</details>


**閉卷自問：**同一介質中 λ 變為 3 倍，ν 變多少？

<details>
<summary>展開答案與最短理由</summary>

變為 1/3。固定 v，用 ν=v/λ；分母變 3 倍，頻率變 1/3。

</details>

### L2｜波數是波長的倒數

^sp-c-l2

**先問：**波數由 40,000 降為 20,000 cm⁻¹，波長方向與數值？

**掛載：**M03 提供「波數讀數與長度單位」→ 本條 L → M04 使用「可供波段判讀的波長」。

**短鏈：**每公分波數 → 取倒數得 cm → 換成 nm → 判波段。

**白話理由：**波數是在固定長度內排得下幾個波，不是在一秒內振動幾次。取倒數才是每個波的長度；波數以 cm⁻¹ 給定，倒數所得就是 cm。

**立即用一次：**40,000 cm⁻¹ 的倒數是 2.5×10⁻⁵ cm，再乘 10⁷ nm/cm 得 250 nm；詳見 C1。

**條件／易錯：**先使波數與波長的長度單位對應。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**一公分塞得進更多完整的波，每個波占的長度就更短。

$$\tilde\nu=\frac1\lambda;\qquad\tilde\nu[\mathrm{cm^{-1}}]=\frac1{\lambda[\mathrm{cm}]}$$

`cm⁻¹` 是長度的倒數，因此先用 cm 取倒數，再轉 nm。捷徑中 $10^7$ 來自 **1 cm＝10⁷ nm**，不是另有一個物理常數。

**波數 ↑ → 波長 ↓ → 在相同傳播條件下頻率與每光子能量 ↑。**

小檢查：20,000 cm⁻¹ 的波長是 40,000 cm⁻¹ 的兩倍。[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-ni1|回 Ni 重建]]

</details>

**先問：**同頻率的燈變亮兩倍，每顆光子的 E 是否變兩倍？

**短鏈：**頻率 → 乘 h → 每光子能量；同頻加亮 → 光子數增加。

**白話理由：**每顆光子的能量由頻率決定。同頻率照得更亮，通常是單位時間的光子數增加，不能因此把每顆光子的能量加大。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**同色的光變亮，與把光改成更短波長，是兩種改變。

$$E=h\nu;\qquad E=\frac{hc}{\lambda_0}$$

| 改哪一項 | 每光子能量 | 總光量的意思 |
|---|---|---|

| 照射更久、條件固定 | 每光子能量不變 | 累積收到的光子數可增加 |

### L5｜吸收如何成為讀數

^sp-c-l5

**白話理由：**先有光照入，才能問檢品使哪些頻率的透射光減少。與參考比較得透光率 T，再換成吸光度 A；光少了也可能是散射等原因，要先把參考與光路做好。

**立即用一次：**參考光量 100、透射 10（相同讀數單位），T=10/100=0.10；題給 log₁₀0.10=−1，A=1。這是自編讀數示意。

**條件／易錯：**參考相容；先排除散射、反射等損失。

<summary>國考必需｜正式原理與來源界線</summary>

$$T=I/I_0;\qquad A=-\log_{10}T$$

### L7｜Raman 的能量交換

^sp-c-l7

**先問：**題本把 Raman 選為 emission，就能說其一般物理機制是螢光嗎？

**掛載：**M02 提供「雷射與可發生能量交換的物質」→ 本條 L → M03 使用「Raman 位移及振動線索」。

**短鏈：**雷射與物質作用 → 非彈性散射 → 讀位移 → 振動資訊。

**白話理由：**一小部分散射光與分子交換能量，回來的頻率便不同。要讀的是相對於雷射的差，不是把樣品當成普通螢光放射體。

**立即用一次：**光子把部分能量留給分子，散射光能量較低，是 Stokes；若從分子取走能量，光子較高，是 anti-Stokes。

**條件／易錯：**振動須改變極化率；背景與照射不得誤判。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**同一支雷射照樣品，收回的少部分散射光頻率與入射光不同。

**入射雷射 → 與物質交換能量的散射 → 讀頻率差 → 推知振動等能量差。**這是 Inelastic scattering（非彈性散射），不同於先吸收成真實電子激發態再螢光放射（S2）。

光子把能量交給分子時，散射光能量下降，稱 Stokes（斯托克斯）支線；反方向能量交換另有 anti-Stokes（反斯托克斯）。本章只需知道「讀位移」，不需多背光路。

Raman 與 IR 都能給振動資訊，但所需的性質變化不同；Raman 看 Polarizability（極化率）變化，IR 看 Dipole moment（偶極矩）變化。「Raman 常補足某些對稱振動資訊」不等於全部對稱鍵必有峰。

### L9｜NMR 的核自旋訊號

^sp-c-l9

**先問：**最多結構資訊是否等於所需量最少、偵測極限最低？

**掛載：**M02 提供「可觀察原子核、靜磁場與射頻」→ 本條 L → M03 使用「化學位移、耦合等結構資訊」。

**短鏈：**磁場建立核能階差 → 射頻激發 → 核訊號 → 核環境線索。

**白話理由：**NMR 從原子核在磁場中的反應取得訊號，再用化學位移、耦合等看局部環境與相互關係。所以問異構物／立體結構時，常比只看少數電子吸收帶有更多資訊。

**立即用一次：**在 NMR、螢光、IR、UV 四選項中，NMR 用射頻，波長最長；500 MHz 例子卻為 0.6 m，不是全都 >10⁹ nm。

**條件／易錯：**頻率依核種與磁場；固態與溶液資訊有別。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**兩個異構物分子式相同，想知道原子的局部環境與相互關係。

**靜磁場 → 可觀察核的能階分裂 → 射頻激發 → 偵測核訊號 → 從化學位移、耦合等建構結構線索。**這不是電子、鍵振動或整個分子轉動三者之一。

NMR 使用 Radiofrequency（射頻）。例如 500 MHz 的真空波長：$3\times10^8/(5\times10^8)=0.6\ \mathrm m$，即 $6\times10^8$ nm；因此不能把「全部 NMR 都 >10⁹ nm」當硬界線。

在本題 NMR／螢光／IR／UV 中，NMR 的波長仍最長。更多結構資訊不等於偵測極限最低；所需量、核種、磁場、探頭與量測時間等共同影響實際表現。

固態 NMR 可比較固態環境；本題溶液 DOSY 依擴散差異區分訊號，不能直接重現溶解前晶格。[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-ni3|回 Ni 重建]]

### L10｜MS 與 LC-MS 的資訊

^sp-c-l10

**先問：**m/z=某個數字，就能不看電荷與加合物直接當中性分子量嗎？

**掛載：**M02 提供「檢品、離子源及必要的 LC 分離」→ 本條 L → M03 使用「離子質荷比、豐度與成分線索」。

**短鏈：**形成離子 → 按 m/z 分析 → 偵測；LC 可先分離混合物。

**白話理由：**MS 要先把檢品轉成可分析的離子，再看質荷比。混合物若先經 LC 分離，不同成分能較分開取得質譜資訊；這正適合本題的微量雜質辨識目的。

**立即用一次：**102-2 第 13 題選 LC-MS：LC 幫忙分離，MS 提供離子質荷比及其他線索；RI 沒有同樣的質譜資訊。

**條件／易錯：**識別電荷、加合物與碎片；勿當中性質量直讀。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**質譜不是中性分子直接貼上質量標籤：**要看電荷數、加合物、分子離子與碎片；本章先知道限制，不展開細算。

### L11｜訊號斜率、噪音與偵測

^sp-c-l11

**先問：**ppb、pg、mol/L 能直接放在同一大小軸排名嗎？

**掛載：**M03 提供「校正斜率、背景變異與題目的性能要求」→ 本條 L → M04 使用「性能判斷與有效比較條件」。

**短鏈：**量的變化 → 訊號變化；對照背景變異 → 評估可辨識量。

**白話理由：**同樣增加一點濃度，讀數變多少是在問靈敏度；低量能否可靠看出來，還要看背景變異。所需檢品量與重複一致程度則是另外兩件事。

**立即用一次：**其他條件及噪音相同，斜率由 m 變 2m，同濃度差產生兩倍訊號差，較有利辨識；這不是完整 LOD 數值公式。

**條件／易錯：**分清靈敏度、偵測極限、檢品量與精密度。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**甲儀器濃度稍增就有很大讀數變化；乙儀器背景很穩定。哪一台更能看出極少量成分？不能只看訊號大不大。

在線性 Calibration curve（校正曲線）的示意中：

$$y=a+mC;\qquad m=\Delta y/\Delta C$$

| 概念 | 真正問的事 | 不等於什麼 |
|---|---|---|
| Sensitivity（靈敏度） | 濃度／量改一點，讀數改多少；此模型為 m | 所需檢品量的倒數 |
| Limit of detection（偵測極限，LOD） | 在方法和背景變異下，何種低量能被可靠辨識 | 只由斜率決定的萬用常數 |
| 所需檢品量 | 此配置與目的要投入多少檢品 | 偵測極限本身；不等於實際被偵測到的量 |
| Precision（精密度） | 重複量測彼此接近程度 | 結構解析能力、儀器價格或靈敏度 |

S1 支持這些概念的區分。噪音與其他條件相同時，較大斜率可幫助辨識小變化；斜率相同時，背景更不穩則更難辨識。這是方向推導，不需在本章另背一套 LOD 數值公式。

#### 題本量級：保留來源，不混單位排名

| 方法 | 題本／舊稿所列 | 應如何使用 |
|---|---|---|
| MS | 常列 pg 級；103-1-22 題幹是 0.1 pg | 本題選 MS；0.1 pg 是 10⁻¹³ g，非 10⁻¹² g |
| Fluorescence | 舊稿 10⁻⁷–10⁻⁸ mol/L | 是濃度，不能直接與 mg 排大小 |
| UV-Vis | 題本 μg；另有 10⁻⁵ mol/L | 是不同表示／條件，不能直接等號 |
| IR | 題本 1–5 或 1–10 mg | 方法條件與來源略異 |
| NMR | 題本 H 約 5 mg 或 10 mg；C 約 20 mg，舊稿另寫 >20 mg | 本題所需量最多選 NMR；不是所有儀器的最低限制 |

**本題集可存的答案：**109-1-26、105-1-28、103-1-22 選 MS；105-2-6 選 NMR。先辨題目問的是濃度、質量還是方法；不使用「選項一有 MS 永遠選它」的口訣。

**反推示範：**訊號上升 → 候選為濃度上升、背景／光源改變、散射或樣品條件改變 → 查空白、標準與操作。[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-ni4|回 Ni 重建]]

此處 C 為濃度，c 為真空光速，兩個符號不可混用。斜率 m 的單位是「訊號單位／濃度單位」；模型 y=a+mC 僅是線性示意。

</details>

<details>
<summary>展開答案與最短理由</summary>

### L12｜晶型資訊的保留與流失

^sp-c-l12

**先問：**ATR 可測晶型，理由是否是它完全不施壓？

**掛載：**M01 提供「原晶型比較目的與檢品狀態」→ 本條 L → M02 使用「相容製樣、方法與參考方案」。

**短鏈：**問原晶型 → 查前處理是否保留固態 → 選可辨識配置。

**白話理由：**同成分可以有不同的固態排列。若要問原晶型，不能先把原排列完全消掉再期待儀器找回它；先選保留相關資訊的製樣與可辨識方法，後續才有足夠資料判讀。

**立即用一次：**先保留固體，再以可區分兩參考晶型的 IR 比較，是相符方案；完全溶解後的本題 DOSY 能看溶液擴散，卻不直接看原晶格。

**條件／易錯：**量測後仍須在 M04 比對；有壓力不等於必轉晶。

<details>
<summary>國考必需｜正式原理與來源界線</summary>

**情境：**相同成分可能以不同固態排列存在。要分辨 Polymorphism（多形性），分析方法須保留並對這些差異有反應。

**原晶體 → 前處理後仍保有相關固態資訊 → 適當量測得到差異 → 與參考比較 → 晶型判讀。**若先完全溶解，原晶格排列通常已不再直接存在；只量溶液成分或離子資訊不能重建它。

| 方法／配置 | 本章判斷 | 必要條件與易錯 |
|---|---|---|
| XRD | 可直接比較繞射特徵 | 看晶格差異與參考圖樣 |
| Raman、合適 IR／NIR | 可用來比較固態特徵 | 要能區分、保留樣品狀態；NIR 常需模型 |
| solid-state NMR | 可比較固態環境 | 固態二字不可省略 |
| 本題 DOSY／diffusion spectroscopy | 113-1-11 選 A，不能直接判原晶型 | 本題為溶液擴散分析 |

| Mull、DRIFT、ATR | 題本列為可用 IR 配置 | 仍要控制研磨、接觸壓力等；不保證完全不改樣 |
| KBr pellet | 題本列不宜用來判多形性 | 壓錠等製備可能改變樣品；不是所有檢品一壓就必轉晶 |

**最重要校正：ATR 的固體常需壓緊接觸晶體，不能把「完全不加壓」當它可用的理由。**S4 說明壓力可能改變物態與譜形。判斷重點是「是否仍保留目標資訊＋方法有無辨識力」，不是一條「有壓力就全部刪除」的規則。

### UV-Vis（紫外－可見光譜）

^sp-c-method-uv

|面向|本方法重點|
|---|---|
|P1／M01 對象與目的|分子對 UV／可見光的吸收；用於含量或特徵比較。|
|P2／M02 作用與條件|電子能階改變；須有可量測吸收、適當溶劑與波長。|
|P3／M03 裝置與讀數|典型 UV 用氘燈、可見用鎢／石英鹵素；讀透射光與吸光度。 λ：nm；T、A 無量綱。|
|P4／M04 判定與限制|定量需校正及適用範圍；單靠寬吸收帶通常不足以確認未知分子結構。|

**辨識句：**定量、溶出監測；pKa、溶解度與分配係數需搭配設計。 [[#^sp-c-l5|回共同鏈]]；[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-methods|回方法快查]]

### Fluorescence（螢光）

^sp-c-method-fl

|面向|本方法重點|
|---|---|
|P1／M01 對象與目的|分子受光激發後的發光；可用於適合分析物的微量分析。|
|P2／M02 作用與條件|先吸收再放光；非輻射途徑、淬熄與環境影響強度。|
|P3／M03 裝置與讀數|常用氙燈；選激發／放射波段後量發光強度。 波長：nm；強度依儀器單位。|
|P4／M04 判定與限制|可有良好偵測能力，但不是每個分子都發強螢光；有時須衍生化。|

**辨識句：**剛性與共軛是線索，不是「一定有螢光」的保證。 [[#^sp-c-l6|回共同鏈]]；[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-methods|回方法快查]]

### Raman spectroscopy（拉曼光譜）

^sp-c-method-raman

|面向|本方法重點|

### C1｜波數換波長：40,000 cm⁻¹

^sp-c-calc1

**題目問什麼：**106-1 第 27 題給波數 40,000 cm⁻¹。求 λ（nm）並判波段。

**已知：**波數 4×10⁴ cm⁻¹；1 cm=10⁷ nm。

**選式理由：**波數是每單位長度的波數，先取倒數得每個波的長度。

**符號與條件：**ν̃：波數，cm⁻¹；λ：波長，先用 cm，再換 nm。

**母式／模型：**

$$\tilde\nu=1/\lambda\quad\Rightarrow\quad\lambda=1/\tilde\nu$$

$$\lambda=\frac1{4\times10^4}\ \mathrm{cm}$$

$$=\frac14\times10^{-4}\ \mathrm{cm}=0.25\times10^{-4}\ \mathrm{cm}$$

$$=2.5\times10^{-5}\ \mathrm{cm}$$

$$=2.5\times10^{-5}\times10^7\ \mathrm{nm}=250\ \mathrm{nm}$$

**得到答案：**250 nm，UV；來源題答案 B。

**驗算：**(4×10⁴ cm⁻¹)(2.5×10⁻⁵ cm)=1；波數減半時波長加倍。10⁷ 是 cm→nm 換算，不是物理常數。

**換條件再做：**C-P1｜改為 20,000 cm⁻¹，求波長與波段。

<details>
<summary>展開練習的紙筆步驟</summary>

λ=1/(2×10⁴) cm=5×10⁻⁵ cm=5×10² nm=500 nm，可見光。波數減半，波長加倍。

</details>

### C2｜混合長度單位與排序

^sp-c-calc2

**題目問什麼：**自編 EX-C2：0.25 μm、500 nm、2×10⁻⁶ m，哪一種每光子能量最大？

**已知：**三個真空／近似空氣波長；1 μm=1000 nm；1 nm=10⁻⁹ m。

**選式理由：**同一傳播條件，光子能量與波長反向；只比較大小不用乘 h。

**符號與條件：**λ：波長；E：每光子能量。所有 λ 先換成 nm。

**母式／模型：**

$$E\propto1/\lambda_0$$

$$0.25\ \mathrm{\mu m}=0.25\times1000\ \mathrm{nm}=250\ \mathrm{nm}$$

$$500\ \mathrm{nm}=500\ \mathrm{nm}$$

$$2\times10^{-6}\ \mathrm m=2\times10^{-6}\times10^9\ \mathrm{nm}=2000\ \mathrm{nm}$$

**得到答案：**250 nm 最短，因此 0.25 μm 的每光子能量最大。

**驗算：**量都已換 nm；不直接比較 0.25、500、2。較短 λ 對應較高 E。

**換條件再做：**C-P2｜0.40 μm、200 nm、1×10⁻⁶ m，哪個每光子能量最大？

<details>
<summary>展開練習的紙筆步驟</summary>

依序換為 400、200、1000 nm；200 nm 最短，故其 E 最大。

</details>

### C3｜比例與一顆光子的能量

^sp-c-calc3

**題目問什麼：**自編 EX-C3：比較 250、500 nm 的每光子 E；再求 500 nm 的 E 量級。

**已知：**真空波長；h≈6.626×10⁻³⁴ J·s，c≈3×10⁸ m/s；500 nm=5×10⁻⁷ m。

**選式理由：**E=hν 且 c=νλ₀，所以 E=hc/λ₀；比值可先消共同常數。

**符號與條件：**E：單顆能量 J；h：J·s；c：m/s；λ₀：真空波長 m。

**母式／模型：**

$$E=h\nu=hc/\lambda_0;\qquad E_1/E_2=\lambda_{0,2}/\lambda_{0,1}$$

$$E_{250}/E_{500}=500/250=2$$

$$E_{500}\approx\frac{(6.626\times10^{-34})(3\times10^8)}{5\times10^{-7}}\ \mathrm J$$

$$=\frac{19.878}{5}\times10^{-34+8-(-7)}\ \mathrm J$$

$$=3.9756\times10^{-19}\ \mathrm J\approx4.0\times10^{-19}\ \mathrm J$$

**得到答案：**能量比 2；500 nm 每光子約 4.0×10⁻¹⁹ J。

**驗算：**J·s×m/s÷m=J；250 nm 較短，能量較大。絕對值只求量級，無需計算機。

**換條件再做：**C-P3｜求 E₃₀₀/E₆₀₀。若把 600 nm 的光加亮，每光子 E 是否變？

<details>
<summary>展開練習的紙筆步驟</summary>

600/300=2。同頻加亮改光子數，不改 E=hν。

</details>

### C4｜ppb 與 pg：先問基準

^sp-c-calc4

**題目問什麼：**來源 103-1 第 22 題的 0.1 pg 是多少 g？另以自編例問：1 ppb 質量分率、1 kg 檢品，共多少待測物？

**已知：**1 pg=10⁻¹² g；質量分率 ppb=10⁻⁹；1 kg=1000 g。

**選式理由：**pg 是質量，可直接換單位；ppb 是分率，必須乘指定檢品質量才得到質量。

**符號與條件：**w：質量分率，無量綱；m_sample：檢品質量 g；m_analyte：待測物質量 g。

**母式／模型：**

$$m_{\mathrm{analyte}}=w\,m_{\mathrm{sample}}$$

$$0.1\ \mathrm{pg}=10^{-1}\times10^{-12}\ \mathrm g=10^{-13}\ \mathrm g$$

$$m_{\mathrm{analyte}}=10^{-9}\times1000\ \mathrm g=10^{-6}\ \mathrm g$$

$$=1\ \mathrm{\mu g}$$

**得到答案：**0.1 pg=10⁻¹³ g；自編 1 kg 例為 1 μg，兩個不同情境不可硬等號。

**驗算：**無量綱×g=g。若要從體積濃度轉進樣質量，還需體積；若要 mol/L→質量，還需分子量等。

**換條件再做：**C-P4｜2 ppb 是質量分率，檢品 250 g。待測物共多少 g 與 μg？

<details>
<summary>展開練習的紙筆步驟</summary>

2×10⁻⁹×250 g=500×10⁻⁹ g=5×10⁻⁷ g=0.5 μg。缺少 250 g 時就不能得這個質量。

</details>

### C5｜h 的單位換算

^sp-c-calc5

**題目問什麼：**自編 EX-C5：把 h≈6.626×10⁻³⁴ J·s 換成 erg·s，並排除原題錯誤量綱。

**已知：**1 J=10⁷ erg；h 是能量×時間。

**選式理由：**只換能量單位，秒仍乘在能量後面；換單位不改常數代表的物理量。

**符號與條件：**h：普朗克常數；J、erg：能量單位；s：時間。

**母式／模型：**

$$1\ \mathrm J=10^7\ \mathrm{erg}$$

$$h\approx6.626\times10^{-34}\ \mathrm{J\cdot s}$$

$$=6.626\times10^{-34}\times10^7\ \mathrm{erg\cdot s}$$

$$=6.626\times10^{-27}\ \mathrm{erg\cdot s}$$

**得到答案：**h≈6.626×10⁻²⁷ erg·s；不是 erg/s，也不是正的 10²⁷。

**驗算：**原題 Q13 選項 A 印為正 10²⁷ 且 s⁻¹，兩處都保留再指出錯誤；E/h 必有頻率 s⁻¹ 的量綱。

**換條件再做：**C-P5｜把 6.62×10⁻²⁷ erg·s 逆向換成 J·s。

<details>
<summary>展開練習的紙筆步驟</summary>

erg→J 除以 10⁷：6.62×10⁻²⁷/10⁷=6.62×10⁻³⁴ J·s；原題 6.62 為近似值。

</details>

#### Q1｜106-1 第 27 題：40,000 cm⁻¹ 屬哪一區？

^sp-c-q1

**來源：**《ch26 光譜分析-光譜概論 .pdf》，106-1 第 27 題，PDF p.6；答案身分：題本印刷答案。

**原題：**波數40,000 cm⁻¹ 落於下列那個輻射區域？

- **(A)** X-ray
- **(B)** 紫外光
- **(C)** 紅外光
- **(D)** 無線電頻率

**真正問什麼：**由波數判輻射區域；先圈題幹的「錯誤／無法／最長／最多／最低」等限定。

**最短完整解題鏈：**由波數判輻射區域 → [[#^sp-c-l2|L2]] 與 [[#^sp-c-f03|F03]] → 40,000 cm⁻¹ → 250 nm，落在題本 UV 區。

**題本印刷答案：B。**在本題選項與條件下判讀相符。

| 選項 | 決定差異的理由 |
|---|---|
|A|250 nm 不在本題 X-ray 區。|
|B|40,000 cm⁻¹ → 250 nm，落在題本 UV 區。|
|C|IR 波長較此值長得多。|
|D|射頻波長更長，不符合。|

紙筆：λ=1/(4×10⁴) cm=2.5×10⁻⁵ cm=250 nm → UV，詳見 [[#^sp-c-calc1|C1]]。

**VQ1｜自編最小變式：**改為 20,000 cm⁻¹，求波長與波段。

<details>
<summary>展開變式答案</summary>

10⁷/(2×10⁴)=500 nm，是可見光；波數減半，波長加倍。

</details>

**回查：**[[#^sp-c-l2|補短鏈]]；[[#^sp-c-f03|必背條件]]；[[藥物分析_光譜概論_複習導航_v3_0#^sp-r-q1|回本題閉卷入口]]。

<details>
<summary>保留的代表題講解與舊變式</summary>

題本選項為 X-ray、UV、IR、射頻。先認 `cm⁻¹` 是波數 → 用倒數取波長 → 轉 nm 得 **250 nm** → 選 **B，UV**。完整紙筆在 [[#^sp-c-calc1|C1]]。

| 選項 | 判讀 |
|---|---|
| A X-ray | 250 nm 不在本題 X-ray 區 |
| B UV | 正確，落在題本 UV 區 |
| C IR | IR 的波長比此值長得多 |
| D 射頻 | 比 IR 更長，不可能是此數值 |

自編變式：改成 4000 cm⁻¹ → 2500 nm，位在 NIR／中紅外的慣用分界；若出分界題須看教材定義，不把邊界硬判成完全不同物理現象。

</details>

#### Q2｜113-1 第 20 題：哪個光源配對錯？

^sp-c-q2

**來源：**《ch26 光譜分析-光譜概論 .pdf》，113-1 第 20 題，PDF p.2；答案身分：題本印刷答案。

**原題：**下列光譜分析法及其光源之配對，何者錯誤？

- **(A)** UV－deuterium lamp
- **(B)** visible－sodium lamp
