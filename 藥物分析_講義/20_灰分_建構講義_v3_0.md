# Ash determination（灰分測定法）｜建構講義 v3.0

本章用重量回答三種不同的問題：**留下多少、減少多少、最後兩次稱量是否夠接近**。先選對問題，才決定分子、分母與判準。適用於一般藥學大學生；計算只用四則、約分與百分率，不用計算機。

本版以所附兩份v1.0筆記及CH11三頁題本為基礎，完整保留8題、32選項與題本印刷答案。原題的化學名稱與文字不改寫；講解另加適用條件。原筆記引用的「統整本11-1」本次未附原頁。

## EX00｜先完成一次最簡單的總灰分題
^ash-ex00

**自編基本例。**取生藥2.000g，依已指定的方法處理並完成稱量品質確認，扣除空坩堝後留下0.050g灰。問總灰分百分率。這裡先不要求記溫度與化學式。

1. M01：要問留下多少比例，所以用殘渣路線。
2. M02：依指定條件取得灰，放冷並確認稱量符合要求。
3. M03：已扣皿，殘渣0.050g、原檢品2.000g；兩者同單位。
4. M04：0.050÷2=0.025；把比例換成百分比，得到2.5%。
5. 回算：2g的1%是0.020g，2.5%就是0.050g。報告「本方法總灰分2.5%」，是否符合規範尚需該品項限度。

**用得到的前置：**百分率就是「每100份有幾份」。此例沒有證明是哪一種金屬，也沒有測出水分；限制來自測量對象，不是算術。

## 最小符號與名詞表

|---|---|
| Ash determination（灰分測定） | 依規定處理後稱量殘留；不是特定金屬鑑定。 |
| Total ash（總灰分）／acid-insoluble ash（酸不溶性灰分） | 前者是整體灰化殘留；後者再取其中耐稀酸處理的不溶殘留。 |
| Residue on ignition（熾灼殘渣，ROI）／sulfated ash（硫酸化灰分） | 本章ROI含硫酸處理；兩名稱在調和方法中相關，實際程序仍依指定條文。 |
| Loss on ignition（熾灼減重，LOI）／loss on drying（乾燥減重，LOD） | 都是淨質量減少；加熱條件與方法目的不同。 |
| Crucible（坩堝）／desiccator（乾燥器）／ashless filter paper（無灰濾紙） | 耐相應條件容器／放冷防吸濕裝置／灰量低且符合方法要求的濾紙。 |
| Analytical balance（分析天平）／muffle furnace（高溫爐、馬弗爐） | 讀取質量的儀器／依方法提供受控熾灼條件的爐體。 |
| [[hydrochloric acid]]（鹽酸）／[[sulfuric acid]]（硫酸） | 稀鹽酸用來處理總灰分、分出酸不溶物；硫酸參與本章ROI規定殘渣形成。 |
| [[calcium carbonate]]（碳酸鈣）／[[calcium oxide]]（氧化鈣）／[[silicon dioxide]]（二氧化矽） | CaCO₃／CaO／SiO₂；化學式幫助辨認物質與質量變化。 |
| Constant mass（恆量／恆重） | 按指定程序重複稱量，差值在門檻內；不要求絕對零差。 |
| Dull-red heat（暗紅熱） | Q02配550–700°C；經驗色稱不能代替可追溯控溫。 |
| m₀；m₁；m₂；mₛ；mᵣ；Δm | 空容器；容器＋原檢品；容器＋末次殘留；原檢品淨重；末次殘留淨重；最後兩次稱量差的絕對值。 |
| g；mg；%（w/w） | 1g=1000mg。相除前換同單位；w/w表示質量比。 |

## A羣｜分清報告量

### L01｜先分留下的或減少的
^ash-l01

**先問：**熾灼殘渣檢查法測的是哪一半？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m01|M01]]；入口取用M01 的分析目的，出口交回M02 的方法路徑。

**短鏈：**選殘渣或減重 → 決定計算分子。

**為什麼：**天平都在量質量，但報告的量不同；名稱中的「殘渣」與「減重」先決定方向。

**立刻用：**2 g 檢品最後剩 0.05 g；灰分的分子是 0.05 g，減重的分子才是 1.95 g。

**條件與陷阱：**乾燥減重不需要把樣品燒光；熾灼殘渣也不能直接當揮發物含量。

### L02｜扣空皿，再找原檢品分母
^ash-l02

**先問：**32 g 能直接當灰分百分比的分母嗎？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m03|M03]]；入口取用M03 的三次含皿稱量，出口交回M04 的殘渣百分率。

**短鏈：**初重減空皿 → 末重減空皿 → 淨重相除。

**為什麼：**皿是承載工具，不能算入藥品；相同皿在相減時消去，分母通常是原檢品淨重。

**立刻用：**空皿 30 g，皿＋檢品 32 g，皿＋灰 30.05 g：0.05÷2×100%=2.5%。

**條件與陷阱：**分母若指定乾燥基準，先依方法換算；不能擅自把酸處理前的總灰分當原檢品。

### L03｜百分率不會自動告訴你是哪種金屬
^ash-l03

**先問：**總灰分合格，能直接宣告砷符合限量嗎？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m04|M04]]；入口取用M03 的方法名稱與百分率，出口交回M04 的有條件品質結論。

**短鏈：**核對測量對象 → 對照限度 → 限制結論範圍。

**為什麼：**同一個殘渣重量可能來自多種鹽或氧化物；總量沒有元素身分資訊。

**立刻用：**總灰分 2.5% 可以與該品項的灰分限度比；不能推出鉛含量或全部重金屬合格。

**條件與陷阱：**殘渣與損失相加為 100% 只適用同一組未另加物質的質量帳；不同方法不互補。

## B羣｜總灰分與熱轉變

### L04｜總灰分包含藥材本身與外來殘留
^ash-l04

**先問：**總灰分偏高就一定是摻砂嗎？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M01 的生藥檢品與方法，出口交回M03 的總灰分淨重。

**短鏈：**依規定灰化除碳 → 冷卻稱量 → 得總殘留。

**為什麼：**藥材內部的無機成分與附著泥沙都可能留下；方法不只秤外來污物。

**立刻用：**原有鈣鹽與外來砂粒可共同增加總灰分。

**條件與陷阱：**未除盡的碳會增加稱得殘留；灰化也可能改變無機鹽，並非所有原物質原封不動留下。

### L05｜看受熱後的去向，不只背鹽名
^ash-l05

**先問：**所有硝酸鹽都不會留下灰，對嗎？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M02 的化合物與熾灼條件，出口交回M03 的相對殘留預測。

**短鏈：**能分解成氣體且無持久金屬殘留 → 不易留灰。

**為什麼：**[[ammonium nitrate]]（硝酸銨）不含金屬，受熱可形成氣態產物；與題中的金屬氧化物或鹽比較，較不易留下灰。

**立刻用：**Q04 在 [[magnesium oxide]]、[[calcium sulfate]]、[[ammonium nitrate]]、[[aluminum phosphate]] 間選 [[ammonium nitrate]]。

**條件與陷阱：**不能把「硝酸根會分解」推成所有金屬硝酸鹽都無灰；金屬部分仍可能留下氧化物等。

### L06｜過度加熱會改變你正在秤的物質
^ash-l06

**先問：**Q08 為什麼不選「避免氧化」？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M02 的灰化溫度、時間、氣氛，出口交回M03 的偏低風險；M04 回查控溫。

**短鏈：**碳酸鈣轉氧化鈣並放 CO₂ → 固體質量減少。

**為什麼：**同一份鈣還在，離開的二氧化碳仍帶走質量，因此灰重會降低。

**立刻用：**CaCO₃ → CaO + CO₂；以 Ca=40、C=12、O=16 算：100份變成56份固體。

**條件與陷阱：**反應取決於條件；550°C 不是一越過就瞬間完全分解的開關，也不是所有樣品都同方向變化。

## C羣｜酸處理與過濾

### L07｜酸不溶性灰分的分母仍是原檢品
^ash-l07

**先問：**酸不溶灰20 mg，分母是總灰100 mg還是檢品2000 mg？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M02 已得到的總灰分，出口交回M03 的酸不溶殘重；M04 的原檢品百分率。

**短鏈：**稀鹽酸煮沸 → 過濾洗滌 → 熾灼不溶物。

**為什麼：**酸處理使可溶部分離開，收集的固體才是要秤的子集合；方法仍回答每份檢品含多少殘留。

**立刻用：**2 g 檢品總灰 100 mg、酸不溶灰 20 mg：酸不溶灰=1%，不是20%。

**條件與陷阱：**主要反映矽質殘留，不是純二氧化矽專一測定；20% 是酸不溶灰佔總灰的另一個比值。

### L08｜賦形劑要連過燃燒與酸溶兩關
^ash-l08

**先問：**Q02 的C為何錯？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M01 的濃縮中藥與配方，出口交回M04 的適用性與成分解釋。

**短鏈：**先看灰化後有無固體 → 再看該固體是否溶於稀酸。

**為什麼：**不溶於水不代表熾灼後還存在，更不代表留下的物質不溶於酸。

**條件與陷阱：**[[talc]]（滑石粉）、[[titanium dioxide]]（二氧化鈦）可能貢獻酸不溶殘留；仍要看條件與實際配方。

### L09｜過濾洗滌是分離，不是裝飾步驟
^ash-l09

**先問：**洗滌不足時，稱到的是否必定全是不溶物？

**掛載：**主站[[藥物分析_灰分測定法_建構講義_v3_0#^ash-m02|M02]]；入口取用M02 的酸處理混合物，出口交回M03 的可比較殘重。

**短鏈：**保留不溶物 → 洗去可溶物 → 定量轉回合適坩堝。

**為什麼：**未洗淨的可溶鹽乾後也會稱到；轉移損失則把真正不溶物弄丟。

**立刻用：**濾紙自帶灰會使結果偏高；轉移時掉失固體通常使酸不溶灰偏低。

**條件與陷阱：**用方法指定的無灰濾紙或相容裝置；Gooch crucible（古氏坩堝）不等於任何燒結玻璃都可進高溫爐。

### 實物怎麼走：樣品、殘渣與讀數
^ash-operations

先依方法處理空容器並稱量，取代表性檢品稱量，才開始加熱。總灰分路徑在規定條件下緩慢灰化；若要酸不溶灰，再用稀鹽酸煮沸灰、收集與洗淨不溶物，轉入合適坩堝重新熾灼。**濾液與洗液帶走可溶物；收集的固體才回到不溶灰稱量。**

ROI的補充完整次序（S05 JP XVIII 2.44）：合適坩堝預熾灼、放冷稱量→取樣→少量硫酸潤濕、溫和炭化→放冷後再按方法加酸→溫和加熱至白煙消失→600±50°C熾灼→乾燥器放冷、稱量。全程避免起火焰。此程序說明為何不能只背「最後加1mL酸」。

同一S05方法另規定：若殘渣超過個論限度且無另規定，按加酸、加熱、熾灼程序以30min期間重複，至兩次殘渣稱量差不超過**絕對0.5mg**，或結果符合個論限度。這不是Q01的**每g檢品0.5mg**，也不是一律再熾灼15min。先看方法條文，再選終點。

LOD用相應乾燥裝置及稱量瓶；LOI用個論指定的熾灼條件。每次需按程序放冷至可比狀態才稱量，乾燥器的乾燥劑要有效。熱秤、吸濕、飛濺、未洗淨與濾材灰都可能使數值失真。

### C01｜殘渣百分率：先扣皿
^ash-c01

**算什麼：**問原檢品中有多少比例成為規定的殘渣。

**母式：**$m_s=m_1-m_0$；$m_r=m_2-m_0$；$R\%=\dfrac{m_r}{m_s}\times100\%$。這是質量比的定義。

**符號與條件：**使用同一已處理且穩定的容器；基準若指定乾燥後檢品，另依該方法處理。

1. 題目要總灰分%，圈「留下的」。
2. 讀m₀=30.000g、m₁=32.000g、m₂=30.050g，全部為g。
3. 先扣皿：原檢品mₛ=2.000g；殘渣mᵣ=0.050g。
4. 選殘渣÷原檢品，不選末次含皿總重。
5. 0.050÷2=0.025，再乘100%=2.5%。
6. 檢查：2g的1%=0.020g，2.5%正好0.050g。
7. 報告總灰分2.5%（自編數據）；是否合格還要品項限度。

### C02｜酸不溶灰：原檢品分母與佔總灰比例

**母式：**$A\%=\dfrac{m_{\mathrm{acid}}}{m_s}\times100\%$；另一個量是$\dfrac{m_{\mathrm{acid}}}{m_{\mathrm{total}}}\times100\%$。兩者都是定義，但問題不同。

### C03｜乾燥或熾灼減重：前後差

### 延伸：化學式比溫度口訣更能防錯

無水[[calcium oxalate]]（草酸鈣）的簡化質量鏈可寫成CaC₂O₄→CaCO₃＋CO，再由CaCO₃→CaO＋CO₂。含結晶水者需另計先失水。這是物料帳示意，不指定某一溫度必然完全轉化；實際熱分解受氣氛、時間與樣品狀態影響。

「磷酸鈣」需先說化學式。只寫Ca₃(PO₄)₂→Ca₂P₂O₇會少一個Ca，不能當已平衡反應；舊1550°C配對因此保留待覈，不畫進可靠反應鏈。
