# pick up 原則套到藥物分析：Ni 核心分析（v1.0）

## 0. 我理解的 pick up

pick up 只有一個本體：一個東西從他處移到我處。撿起、接收、學會、接人都是這個本體落在不同語境。
所以講義要先寫本體，再讓例子從本體長出來；讀者看到每個例子，都能拿它和本體核對。

套到藥分，對照目前的成果，有三件事要改：

- **276 條生成規則多半在投影那一層，不是本體。** 例如 hplc.R3「越像固定相越晚出」、R4「移動相越像固定相沖提越強」、R5「pH 讓中性比例變大 tR 變長」、R6「離子對」，四條其實都是同一個本體：分子在兩相之間分配。現在它們是並排的四條規則，讀者要記四次。
- **五軸是座標，不是本體。** 五軸（適配、位置、寬度、換量、條件）回答「這題落在哪」，本體回答「為什麼會這樣」。兩者要並存：本體生出投影，五軸給每條投影定位。
- **v1.1 精華頁照規則題數排，不照本體排。** HPLC 那一句「分子待在像自己的那一相，偵測器只看得見它身上的把柄」把兩個引擎擠成一句，違反「一個本體一句」。另外，頁面上的類比沒有標清楚哪些是機轉橋、哪些只是記憶鉤。

## 1. 藥分的學習單位

藥理的單位是「藥」，一張向量藥卡就是一個單位。藥分有兩層單位：

| 層 | 單位 | 數量 | 對應藥理 |
|---|---|---|---|
| 方法 | HPLC、GC、UV、非水滴定、水分…… | 34 章，合併成 21 份 | 一章 |
| 零件 | 偵測器、離子源、質量分析器、固定相、光源、滴定液、指示劑、鑑別試劑 | 估計 60–80 張 | 高頻藥 250 張向量卡 |

方法單位最多 3 個引擎。零件是方法引擎落地的具體東西，各自也有一個本體。例如：
- **ECD**：⁶³Ni 放出電子，電負性基團把電子吃掉，電流就下降。
- **FID**：把有機碳燒成離子，再量電流。

## 2. 試算：五章改成「本體 → 投影」後各要幾個引擎

方法：把每章 16 年的生成規則掛到本體底下，數每個本體接住幾題（主章題數）。

| 章 | 題 | 引擎（本體） | 接住 | 共用引擎 | 孤點 |
|---|---:|---|---:|---:|---:|
| HPLC | 137 | ① 分配：分子在油的固定相和水的流動相之間分配，越像固定相留越久<br>② 把柄：偵測器只讀分子身上一種物理性質<br>③ 矽膠表面：填料表面的 Si–OH 會抓鹼、怕高 pH | 79＋35＋13＝127（93%） | 9（面積比＝濃度比） | 1 |
| GC | 66 | ① 氣化門：只有能變成氣體、受熱不壞的分子跑得動<br>② 分配：極性相似留得久<br>③ 把柄：偵測器 | 31＋8＋16＝55（83%） | 11（寬度 8、定量 3） | 0 |
| 非水滴定 | 43 | ① 拿掉搶質子的水，溶劑決定強弱尺<br>② 質子往更想要它的地方走（方向、指示劑） | 27＋14＝41（95%） | 0 | 2 |
| UV | 111 | ① 光子能量要對上電子能隙<br>② 每一層吸掉同比例 → A＝εbc | 68＋30＝98（88%） | 6（光源、槽、偵測器配波段） | 7 |
| NMR | 114 | ① 磁場把核自旋分成能階，吸收 RF<br>② 核外電子遮蔽外場 → δ<br>③ 鄰核自旋經鍵傳話 → 裂分與 J | 48＋31＋30＝109（96%） | 0 | 5 |

讀法：
- **每章 2–3 個本體就接住 83–96% 的題**，剩下的不是孤點，而是幾個橫跨各章的共用引擎。
- 這是規則層級的對應，還不是逐題的遮住測試。真正驗收要逐題做：只看本體，能不能推出正解。
- NMR 的 δ 刻度（10 題）放在 ② 底下：順序能從遮蔽推，但 ppm 數字是孤點。這種「方向可推、數字要記」的題要拆開寫。

## 3. 共用引擎：pick up 在藥分最強的地方

pick up 的精神是：同一個本體落在不同語境，就是不同的例子。藥分最好的例證是共用引擎，同一個本體會在好幾章長出不同的題：

| 共用引擎（本體） | 落在哪些章 | 例子 |
|---|---|---|
| **分配**：分子在兩相之間分配，像誰就待誰那邊 | 萃取、SPE、層析概論、TLC、HPLC、GC、SFC、CE（MEKC） | LLE 選溶劑、Rf 大小、逆相出峰順序、Carbowax 抓醇、MEKC 依 logP 排 |
| **解離**：pH 對 pKa 決定帶不帶電 | 水溶液、萃取、HPLC、CE、UV、TLC、非水滴定 | 弱酸壓低 pH 才萃得出、才留得住；CE 遷移方向；UV 酚在鹼中紅移；TLC 加醋酸減拖尾 |
| **把柄**：探針只讀分子身上一種性質 | HPLC、GC 偵測器、TLC 呈色劑、MS 離子源、定性鑑別 | ELSD 看不揮發、ECD 看鹵素、ninhydrin 看胺、ESI 看會帶電的、Dragendorff 看生物鹼 |
| **能隙**：光子能量要對上一個能階差才被吸收 | 光譜概論、UV、IR、NMR、原子光譜、螢光 | 共軛長 → 能隙小 → λ 長；k 大 μ 小 → 波數高；B₀ 大 → ΔE 大 |
| **計量**：讀數和量成正比，比例係數由反應式或標準品決定 | 全部 | Beer、[α]、KF 的 1：1、當量、內外標、油脂各價 |
| **擴散**：分子群散開讓峰變寬 | 層析概論、HPLC、GC、CE | van Deemter、毛細管沒有 A 項、CE 只剩縱向擴散 |

這 6 個本體在藥分的地位，等於藥理的總論。每章的引擎多半是它們之一落在這章的特殊語境。例如 GC 的「氣化門」就是「分配」遇上「移動相是氣體」這個語境。

## 4. 封閉動詞：藥分版

藥理 v2 用 14 個封閉動詞（放大、搶位、煞車……）給每條推導鏈開頭。藥分的物理動作也可以收斂成一份封閉表，草案 14 個：

| 動詞 | 意思 | 主要章 |
|---|---|---|
| 分配 | 在兩相間按相似度分到兩邊 | 萃取、層析各章 |
| 解離 | 得失質子而帶電或不帶電 | 水溶液、萃取、HPLC、CE |
| 吸收 | 能量對上能階差就被吃掉 | UV、IR、NMR、AAS |
| 放光 | 激發態回基態時放出光子 | 螢光、AES |
| 散射 | 光撞到分子或顆粒改方向 | Raman、ELSD、比濁 |
| 遮蔽 | 電子雲擋住外場或改變能階 | NMR δ、UV 助色、IR 鍵強 |
| 耦合 | 鄰近自旋或振動互相傳話 | NMR 裂分、IR 指紋 |
| 游離 | 中性分子被弄成離子 | MS 離子源、FID、ECD |
| 遷移 | 帶電粒子在電場或磁場中移動 | CE、MS 分析器 |
| 擴散 | 分子群自己散開 | 峰寬各章 |
| 計量 | 照反應式定比例反應 | 各種滴定、KF、油脂價 |
| 沉澱 | 溶度積夠小就析出，軟配軟最牢 | 沉澱滴定、重量、限量、鑑別 |
| 轉電子 | 電子從低 E° 流向高 E° | 氧化還原、電化學、碘量 |
| 燒失 | 加熱讓東西揮發或分解 | 水分、灰分、GC 進樣、熾灼 |

每個本體開頭標一個動詞。讀者看到「沉澱」，就知道接下來要用 Ksp 和軟硬酸鹼推。

## 5. 治、價、性在藥分的意思

| 標籤 | 藥理 | 藥分 |
|---|---|---|
| 治（綠） | 用途 | 能做什麼：適用的分子、方法、場合 |
| 價（紅） | 代價、副作用 | 做不到什麼、會被什麼騙：不適用、干擾、誤差、陷阱 |
| 性（藍灰） | 性質 | 條件旋鈕怎麼推、數字特徵、操作要點 |

藥分裡很多「治」和「價」確實是同一個向量落在不同語境，不該拆成優點欄、缺點欄：

- **矽膠表面的 Si–OH**
  - 治：正相、HILIC 就靠它抓極性分子。
  - 價：逆相時它抓住鹼性藥，造成拖尾；pH 太高，矽膠會溶掉。
  - 性：用 end-capping、低 pH、加 TEA 搶位去處理。
- **ECD：電負性基團吃電子**
  - 治：鹵素農藥、硝基化合物超靈敏。
  - 價：烷、胺、醇幾乎看不到；要用放射源。
- **GC 氣化門**
  - 治：殘留溶劑、精油、乙醇。
  - 價：蛋白質、熱不安定藥、鹽類進不去。
  - 性：用衍生化把氫鍵蓋掉，才跑得動。
- **非水滴定：拿掉搶質子的水**
  - 治：弱鹼溶在冰醋酸、用 HClO₄ 滴；弱酸溶在 DMF、用 NaOCH₃ 滴。
  - 價：水分要除乾淨，否則它會回來搶質子。

## 6. 現有頁面裡本體寫得太下游的地方（acetazolamide 型錯誤）

| 現在的寫法 | 問題 | 往上提一層 | 提了以後多推得出什麼 |
|---|---|---|---|
| UV：「π 共軛越長，λmax 越長、ε 越大」 | 這是投影 | **光子能量要對上電子能隙**；共軛延長讓能隙變小 | 助色基、pH 位移、躍遷種類排序、n→π* 弱，再加上和 IR、NMR 共用的同一個本體 |
| 水分：「1 個 I₂ 吃 1 個 H₂O」 | 這是計量投影 | **水是 I₂ 氧化 SO₂ 的必要反應物** | 1：1 計量；醛酮和甲醇生成水會干擾；還原劑吃 I₂ 會干擾；多出的 I₂ 讓雙鉑電極通電成為終點；吡啶或咪唑要接住生成的酸 |
| 非水滴定：「乙酸汞＝除鹵劑」 | 寫的是動作，不是原因 | **X⁻ 在冰醋酸裡太弱，HClO₄ 推不出終點 → 換成醋酸中最強的鹼 AcO⁻** | 醋酸鹽可直接滴、硫酸鹽只滴到 HSO₄⁻、為什麼汞鹽要過量 |
| HPLC：「分子待在像自己的那一相，偵測器只看得見它身上的把柄」 | 兩個引擎擠成一句；矽膠表面這個第三引擎沒寫 | 拆成分配、把柄、矽膠表面三個本體 | 拖尾、end-capping、pH 2–8 限制、正相、HILIC 全掛到第三引擎 |

## 7. 機轉橋和記憶鉤

現有頁面的類比要逐條標清楚：

| 類比 | 判定 | 理由 |
|---|---|---|
| CE 的電動走道（EOF＋自走速度相加） | 機轉橋 | 速度真的相加，可以推遷移順序 |
| AAS 的教室（火焰只叫醒少數人） | 機轉橋 | 就是 Boltzmann 分布，可以推 AES 只亮鹼金屬 |
| UV 的琴弦（弦越長音越低） | 半橋 | 「長度越長、能階越低」對應箱中粒子，可以推；「弦越粗聲越響＝ε 大」只是記憶鉤 |
| HPLC 的聯誼 | 記憶鉤 | 好記，但推不出 pH 或離子對的方向 |
| GC 的機場安檢 | 記憶鉤 | 好記，推題還是要回到「氣化門」本體 |

## 8. 怎麼用 16 年題庫驗收本體

你的三個檢查，都可以用 1280 題逐題做：

- **遮住測試**：每題只給本體，判斷能不能推出官方答案，標成可推、要第二引擎、孤點三類。目標是每章可推 ≥ 90%，孤點標考次。
- **上游測試**：一題要靠兩個不相干的原因才解得通，就表示本體不夠上游，或者那是第二引擎。這可以從題目同時掛兩條規則的地方找。
- **反向測試**：從題幹的現象一路追回本體，例如「鹼性藥拖尾」追回矽膠表面、「FT4 假性升高」那類假象題追回把柄或計量。
- **舊題找本體、新題驗收**：用 100–107 年的題寫本體，看 108–115 年的題能不能從本體推出。規則層級是 69%，本體層級預期更高，這是本體夠不夠上游的客觀指標。
