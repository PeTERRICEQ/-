# 藥分章節代碼（每題選一個主章；真的橫跨兩章才加第二個）
## 儀器分析
spec 光譜概論：電磁波區段、能量／波長／波數換算、光源與偵測器通論、Beer 定律以外的通論
uv   紫外–可見光：Beer 定律、ε、A(1%,1cm)、發色團、溶劑效應、pKa 光譜法、比色法
flu  螢光／磷光／化學發光
ir   紅外光（含 NIR、ATR、KBr、FT-IR 組件）
ram  拉曼
nmr  核磁共振（1H、13C、2D）
aas  原子光譜：原子吸收、原子發射、焰光、ICP
ri   折光率
pol  旋光度、比旋光度、ORD／CD、鏡像比例（非層析法）
ext  萃取與樣品前處理：LLE、分配係數、SPE、SFE、Soxhlet、衍生化前處理
chr  層析概論：k′、α、N、H、Rs、van Deemter、峰形、離子交換、粒徑排除、親和、對掌固定相通論
tlc  薄層／紙層析、Rf、顯色劑
hplc 液相層析：正逆相、動相強度、偵測器、離子對、IC、內外標、梯度
gc   氣相層析：管柱、載氣、偵測器（FID/TCD/ECD…）、溫度程式、Kovats I、頂空
sfc  超臨界流體層析
ce   毛細管電泳：EOF、CZE、MEKC、CGE、CIEF
ms   質譜：游離源、質量分析器、同位素峰、碎裂、氮規則、不飽和度（若題目是質譜情境）
## 傳統分析
val   分析確效、誤差、統計、有效數字、精密度／準確度、LOD/LOQ、線性
gen   藥典通則用語與操作：取量、溶液濃度表示（1→10）、器皿、恆量、乾燥、安定性
phys  物理常數測定：比重、黏度、熔點、沸點／沸程、凝固點、溶解度
aq    水溶液與酸鹼理論：pH、pKa、緩衝、離子化比、指示劑變色原理、溶劑的酸鹼性（拉平／區分）
neut  水溶液中和滴定：標準液、一級標準品、當量、滴定曲線、指示劑選擇、雙終點
naq   非水滴定：過氯酸、甲醇鈉、冰醋酸、乙酸汞
ppt   沉澱滴定與重量分析：Mohr、Volhard、Fajans、Ksp、沉澱秤重
edta  錯合滴定：EDTA、金屬指示劑、pH 控制、遮蔽
redox 氧化還原滴定：碘量（iodimetry/iodometry）、KMnO4、溴量、亞硝酸鈉、鈰量、重鉻酸
echem 電化學：電極、Nernst、電位滴定、極譜、離子選擇電極、導電度、雙鉑電極
kf    水分測定：Karl Fischer、共沸蒸餾、乾燥失重
ash   灰分、酸不溶性灰分、熾灼殘渣
fat   油脂常數：酸價、皂化價、酯價、碘價、羥價、乙醯價、過氧化價
oil   揮發油測定、乙醇含量（蒸餾法）
lim   限量試驗：重金屬、砷、鐵、氯化物、硫酸鹽、易碳化物
id    定性鑑別反應：離子／官能基呈色、藥典鑑別試驗、維生素等特定藥品呈色、氧瓶燃燒等元素分析前處理
bio   生物／免疫分析：ELISA、RIA、生物檢定、酵素法
oth   以上都不是（熱分析 DSC/TGA、X 光繞射、溶離試驗……），請在 note 寫具體主題
