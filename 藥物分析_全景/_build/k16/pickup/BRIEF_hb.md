## 二、本科的對應（使用者已確認）
- 22 份文件的分法不變，每份一個 spec。**不畫結構式**。
- **單位**＝零件、試劑、檢驗項目（向量卡一張一個）。
- **主流程（① 大循環的閘門）**＝五站 **源 → 樣 → 選 → 測 → 算**：
  - 源：能量或試劑從哪裡來（光源、載氣與流動相、滴定液、標準品）。
  - 樣：檢品能不能上、要不要前處理或改造（溶解、萃取、衍生化、乾燥、灰化）。
  - 選：怎麼分開或怎麼只挑到目標（固定相、溶劑、指示劑、遮蔽劑、單色器、質量分析器）。
  - 測：讀什麼訊號（偵測器、終點、吸光、電位、重量）。
  - 算：讀數怎麼換成量或判定（計量、Beer 定律、檢量線、確效指標、限量判定）。
  - 一站內容太多可以拆成兩個閘門（id 寫 `選1`、`選2`，名稱寫「③ 選（一）：…」）；某站真的沒東西可以省略，但順序不可改。gate id 的**第一個字必須是源樣選測算之一**（決定顏色）。
- **門派（⓪ 的 sect）＝ ① 的閘門**：每個 sect 的 `gate` 指向一個 gate id，一個閘門對一個門派（拆成選1、選2 就是兩個門派）。左右側 `side` 自己配，讓左右高度大致平衡。
- **中心比喻**：用 index.json 該章的 `mid`，或 pick up 版的總本體一句話（短，6–10 字），`sub` 一行寫兩個本體。
- **L 編號**：
  - 有講義的章沿用 app_data.json 的 L 編號（L01…）。合併文件（例：IR 與 Raman、水分與灰分、折光與旋光）各子章 L 會撞號 → 每個子章用自己的 1–2 個大寫字母前綴＋兩位數（例：IR 用 L01、Raman 用 R01；水分 W01、灰分 A01）。
  - 沒有講義的章（酸鹼、氧化還原、確效、沉澱鑑別、油脂等）自己編號，同樣「大寫字母前綴＋兩位數」。
  - 講義沒有、但國考常考的旁支可以補，用新前綴（例：X01）。
  - 格式一定要符合正規式 `[A-Z]{1,2}\d{1,2}`，`➔ L05` 才會變成可點的連結。

## 三、spec 欄位（全部照 hb_hplc.py）
新建 `essence/specs/hb_<key>.py`，`SPEC = dict(...)`：
- `key`（和 `<key>2.py` 相同）、`file`（例 `"04_IR與Raman"`，和現有 PDF 檔名前綴相同）、`name`、`keys`（照 `<key>2.py` 的 keys，用來算考 n）、`drills="q_<key>"`（有題型練習時）、`v11="<key>"`（有 v1.1 時）、`one`（全章一段話：本體＋分類＋關鍵分界）。
- `gates`：每個 gate 有 `id`、`name`、`one`（閘門一句）、`L`；每條 L 有 `L`、`v`（1–2 個封閉動詞，只能用 lib.VERBS 的 16 個）、`name`（問句或短標題）、`vec`（綠底推導鏈：A → B → C → 結果，是**本體**）、`proj`（`("治"|"價"|"性", 一句)`，3 個左右）。
- `cond`：左欄「樣品條件 → 走哪條路」4–7 列，每列結尾 `➔ Lxx`。
- `cost`：騙子帶（干擾、基質、系統誤差、常見錯答）6–9 列，結尾 `➔ Lxx`。
- `radial`：`center`、`sub`、`caveat`（反直覺的一兩件事）、`legend`、`sects`。每個 sect：`name`（「X派｜…」）、`slogan`、`gate`、`side`、`br`（分支）。分支：`name`、`hint`、`L`（列表）、可選 `risk`（`red`／`grn`）、`kl`（類別）。
  - **每類一列**。類別：`name`；`see`（**看到**：考卷上會出現的縮寫、代號、商品名、試劑名，2–3 個）；`touch`（**摸到**：英文構造或實體，一行）；`axis`（「同一個 X；差在 Y」，獨門一支寫「獨門一支，不用比 Δ」）；`items`（**組成只寫 Δ**：`(名稱, "差異｜第二個差異")`。名稱前加 `~` 會畫成虛線藥丸（非零件，或不考名字的）；差異文字前加 `!` 會變紅（代價、陷阱））。考 n 由 hb.py 依名稱與別名從題庫自動算，不用自己填。
- `cards`：本章零件向量卡，10–16 張，從 pick up 版的 vcard 升級。每張：`name`、`sub`（英文全名）、`alias`（題庫裡會出現的寫法，用來算考 n 與連結；不要放太短、會誤中別字的別名）、`verbs`、`L`（大循環位置）、`vec`（本體一句，括號註明共用引擎）、`proj`（`(分組, 治/價/性, 一句)` 2–4 列）、可選 `iso`（孤點）、`tags`（只用六個共用引擎名：分配、解離、把柄、能隙、擴散、計量；看 `hb.py` 的 `ENGINE_TAGS`）、可選 `code`（代號）、`prop`（左欄性質 2–4 列）。
- `cards_per_page=4`。
- `terrain`：③ 地形圖 6–10 列 `(分子或樣品帶什麼, 本章用什麼（<<卡名>>）, 為什麼（本體）, 代價)`；`terrain_read` 一段讀法。滴定、鑑別類的章，第一欄寫「樣品特性」（例：弱鹼、水不溶、含鹵素）。
- `names`：④ 名稱與代號 8–15 列 `(縮寫或代號, 拆字說明, 連到哪：<<卡名>> 或 ➔ Lxx)`。
- 文字裡 `<<卡名>>` 會變成藥丸：有這張卡就是綠色可點，沒有就是灰色。`**粗體**` 可用。

## 五、寫作規範
- 台灣繁體中文、短句、主動語態；不用破折號插入語；不用「不是 X 而是 Y」句型；不寫「真正的」「關鍵是」這類填充詞。

- 數字、方向、官方答案要正確；官方答案和原理矛盾時，寫進 cost 並標題號。
