# ①②③④⑤ 與目錄：各頁規格

## 目錄＋圖例（第一頁）

- 標題「章名｜精華 v2.0」、一段 ONE（全章一段話：本體＋怎麼分類＋關鍵分界）。
- 學習路線（照順序、全部可點）：
  ⓪ 門派擴散記憶圖 → ⓪→① 位置對照 → ① 大循環推導版 → ② 向量卡 → ③ 結構地形圖 → ④ 字根 → ⑤ #標籤反查。
- 原精華舊版：逐頁連結（對答案用）。
- 本章向量卡清單：「No.排名 藥名」＋封閉動詞，可點。
- 每一頁左上角都有「← 目錄」。PDF 書籤和目錄同步。

## ① 大循環推導版

- **閘門**：依因果分成幾組，每組一個方框（標題＋「閘門一句」），顏色固定一種。
- **蛇形排列**：每列 `cols` 個（2 或 3），偶數列反向，箭頭順著因果走。
- **每條 L 直接寫好推導鏈（本體）**，不留空格讓學生手寫：
  - `L 編號`＋封閉動詞圖示＋名稱。
  - 綠底推導鏈：「A → B → C → 結果」。
  - 投影列：`治／價／性／病`＋藥丸＋結果一句。
- **支線**（aux）：放在主流程下方，例如藥物命運、救援。
- **反噬帶**（cost）：最下面一橫條，放副作用、抗藥、回授；寫明「副作用＝代償或被擋的旁支」。
- **病人條件**（pt）：左欄，寫「條件 → 挑哪一條迴路」。
- **藥丸三種**：
  - 本章有卡：綠色、可點，跳到卡。
  - 別章的高頻藥：灰色，標「No.排名」。
  - 其他或病因：灰色；`~` 開頭為虛線。
- L 編號沿用講義；講義沒有的旁支用字母開頭（例：D1–D3 抗憂鬱旁支、U1 痛風、F1 抗黴菌、I1 免疫抑制）。

## 封閉動詞表（14 個，只准用這些，跨章才比得起來）

| 動詞 | 意思 |
|---|---|
| 放大 | 訊號被放大或被打開（致效劑、正向調節、增加釋放） |
| 回彈 | 下游回頭壓上游，或擋掉後反彈（負回授、反射、戒斷） |
| 搶位 | 長得像的分子搶同一個位子（競爭拮抗、競爭受質） |
| 組裝 | 把零件接成成品；擋它＝做不出來 |
| 煞車 | 把正在跑的電流或訊號壓下來 |
| 儲存 | 先存起來再慢慢放 → 效果延遲或延長 |
| 外漏 | 庫存被擠出或破掉，一次流出 |
| 載運 | 載體、轉運體、結合蛋白搬運 |
| 轉換 | 同一分子改一刀，活性升或降（前驅藥活化、代謝） |
| 遮蔽 | 訊號還在，接收端聽不到 |
| 攔截 | 在路上就被抓住或包住（螯合、樹脂、抗體中和） |
| 清除 | 被代謝、排出、殺死或燒掉 |
| 冒充 | 假受質被當真的處理 → 產物錯誤或卡死 |
| 破壞 | 直接打斷結構（烷化、膜打洞、自由基） |

其他科目可以換成自己的封閉集（12–14 個），但同一科內只准用那幾個。

## ② 向量卡（每顆高頻藥一張）

- **右欄**：
  - 本體一句（配封閉動詞）。
  - 投影列：`分組｜治／價／性｜語境 → 結果`，每列都要能從本體推回去。
  - 孤點（紫色）：推不出來的硬事實，越少越好。
  - #標籤：跨章共同現象（例：#零階動力學、#弱鹼困在酸、#前驅藥切殼）。
- **左欄**：
  - 結構圖，鑰匙部位上色（綠＝key scaffold、黃＝halogen、橙＝acid、藍＝basic amine、紅＝cleavable ester）。
  - 生理 pH 下的電荷。
  - logP 刻度條（沒有實測就用 Crippen 計算值）。
  - t½ 對數尺（秒到月）。
  - INN 字根框：字根 → 機轉 → 母核（英文）。
  - 國考紀錄：考過的年份章（由題庫自動比對）。
- **右上**：大循環位置（可點回 L）；下一行是家族骨架（英文）。
- 別章的高頻藥可以借進本章（BORROW），但要指定它在本章的 L，否則不連 L，避免連到同號的別條。

## ③ 結構地形圖

- 一族一把鑰匙（key scaffold，用 SMARTS 上色）。
- 節點：結構圖＋三件事——改了哪裡、換到什麼、付出什麼代價。
- 箭頭上寫「改了哪個位置」。
- 每族結尾一段讀法：1–3 句講清這族的結構與活性關係。
- 官能基與骨架一律英文（aryloxypropanolamine、4-anilinoquinazoline、β-lactam）。

## ④ INN 字根

- 每列：字根 → 機轉 → 母核（英文）→ 本章成員（有卡的綠色可點）。
- 只用字根資料庫裡有的字根；資料庫沒有的不硬湊。

## ⑤ #標籤反查

- 每個標籤一列：本章的藥（綠色可點）＋他章同形狀的藥。
- 目的：同一條規則在不同章再撞見一次，就記牢一次。

## 超連結（全部要有，0 斷才算完成）

- 藥名 → 卡；卡 → L；字根 → 字根表；標籤 → 反查頁；⓪ 分支 → L；⓪ 門派色塊 ↔ 位置對照；每頁「← 目錄」；PDF 書籤。
- 產生時自動統計 links 與 missing；missing 必須為 0。
