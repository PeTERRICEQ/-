# 精華講義 v2.0 的核心思想（藥理藥化版 → 給其他科目沿用）

> 材料前提：16 年國考題庫（100–115，已拆成考點）＋各章大小循環講義（L 編號）。

## 一句話

**先寫本體，其他都是投影。** 每個學習單位都要先有一條從第一性原理推得出來的因果鏈（本體），用途、代價、性質都從這條鏈推出來；推不出來的才是孤點，集中放、標明要背。考題不是拿來背的清單，是拿來驗證骨架有沒有長對。

## 0. pick up 原則（整套講義的地基，先讀懂這一段）

### 這個名字從哪裡來

英文 `pick up` 在字典裡有好幾個意思：撿起、接收訊號、學會技能、開車接人。
如果卡片寫「pick up：撿起、接收訊號、學會、接人」，讀者就得死背 4 個互不相干的碎片。
但其實它們只有一個本體：**「一個東西從他處移到我處」**。
- 放到地板的語境，就是撿起。
- 放到電波的語境，就是接收訊號。
- 放到技能的語境，就是學會。
- 放到乘客的語境，就是接人。

**C、D、E、F、G 說到底都是 A。** 講義的工作就是找出那個 A，先寫 A，再讓 C–G 從 A 長出來。

### 規則

1. **向量走在例子前面。** 先寫一句本體（A），再列投影（C–G）。讀者看到每個例子時，要能立刻回答「為什麼它屬於這個分類」：腦袋拿例子和向量核對，核對得上就記住了。
2. **本體必須是真正的上游原因。** 寫得太下游，投影會推錯。
   - 反例：acetazolamide 寫成「把 HCO₃⁻ 往尿裡倒 ⇒ 體液減少 → 降眼壓」是錯的。降眼壓是因為睫狀體的碳酸酐酶被擋、房水做不出來，跟脫水無關。
   - 往上提一層，寫成「卡住碳酸酐酶 ＝ 全身的 HCO₃⁻ 生產線停工」，就全部通了：眼 → 房水↓；腎 → HCO₃⁻ 倒進尿 → 血變酸（高山症、矯正代謝性鹼中毒）、尿變鹼（磷酸鈣結石、NH₃ 回收 → 肝腦病變）。
3. **療效和副作用放在同一組投影裡，不要拆成兩欄。** 它們常常是同一個向量落在不同器官或不同語境。拆成「專長」「前科」兩欄，等於把一件事拆成兩份死背。用顏色區分就好：治＝綠、價＝紅、性＝藍灰。
4. **一個單位最多 3 個引擎。** 真的有兩三個獨立原因時，就分成兩三個本體，各自掛投影；不要硬擠成一句。
5. **推不出來就老實放進孤點。** 不要編假因果。假因果在考場上會反咬，被硬掰的連結比沒有連結更危險。
6. **分清「機轉橋」和「記憶鉤」。** 機轉橋是真的因果，可以拿來推題；記憶鉤只是方便記，要標明不能拿來推題。

### 怎麼檢查本體寫對了沒有

- **遮住測試**：只看本體，遮住投影，自己一條一條推出來。推不出來的那一列，若不是本體寫得不夠上游，就是該搬去孤點。
- **上游測試**：如果某條投影需要另一個不相干的原因才解釋得通，就表示本體寫得太下游（往上提一層），或那其實是第二個引擎。
- **反向測試**：拿一道考題的題幹（某個症狀、某個條件），要能一路追回到本體。

### 藥理藥化的實例

> **Methotrexate 本體：【卡住 DHFR ＝ 斷掉一碳單位供應 → 所有正在抄 DNA 的細胞停工】**
> - 治：白血病、絨毛膜癌、子宮外孕（滋養層）、RA 與乾癬（活化的淋巴球與表皮）
> - 價：骨髓抑制、黏膜炎、致畸（都是「分裂快」的組織）
> - 性：leucovorin 是已還原好的一碳載體 → 繞過 DHFR 救援
> - 孤點：肝纖維化、肺炎（不是這個向量推出來的）

### 套到藥物分析時的樣子（示範格式，內容請依講義核對）

> **逆相 HPLC 本體：【分子在「油的固定相」和「水的流動相」之間來回分配，越油留得越久】**
> - 性：流動相有機比例↑ → 整體變油 → 所有成分提早出峰
> - 性：弱酸在高 pH 解離 → 變水溶 → 早出；所以酸性藥用酸性流動相壓住解離（ion suppression）
> - 治：離子對試劑把帶電藥物包成中性的「油」→ 留得住
> - 第二引擎【鹼性胺和矽膠殘留 silanol 的離子作用】→ 價：拖尾 → 解法：end-capping、低 pH、加 triethylamine

> **GC 本體：【只有能變成氣體、而且受熱不壞的分子，才能被載氣帶著跑】**
> - 價：熱不穩定的藥會在注射口分解 → 不適用
> - 性：–OH、–NH、–COOH 會形成氫鍵 → 不易揮發 → 用 silylation 等衍生化把氫鍵蓋掉 → 才跑得動

> **非水滴定本體：【拿掉水這個「搶質子的對手」→ 弱鹼、弱酸的酸鹼性被放大到滴得出來】**
> - 治：弱鹼藥（amine）溶在 glacial acetic acid，用 perchloric acid 滴；弱酸溶在 DMF 等溶劑，用 sodium methoxide 滴
> - 價：樣品和試劑的水分要除掉，因為水會回來搶質子
> - 性：hydrohalide 鹽的 Cl⁻ 在醋酸中太弱、滴不到 → 先加 mercuric acetate 換成 acetate，再滴

## 1. 本體、投影、孤點（落到卡片上的格式）

- **本體**：一句話講完「它做了什麼 → 因此發生什麼」，再配一個封閉動詞。
- **投影**：每條寫成「語境 → 結果」，分成三種。
  - 治：用途。
  - 價：代價與限制。
  - 性：性質。
  - 每條投影都要能從本體推回去，推不回去就不是投影。
- **孤點**：推不出來的硬事實。集中放、標成紫色，越少越好。
- **讀法**：先讀本體 → 遮住投影自己推 → 再對答案。

## 2. 大循環推導版（取代留白手寫格）

> 理解與記憶拆開：大循環負責理解；記憶交給 ⓪ 門派擴散記憶圖（規格見 `.claude/skills/essence-handout/references/radial.md`）。

- 每條 L 都**直接寫好推導鏈**，再接上對應的藥。不要留空格讓學生自己寫，手寫推導很花時間。
- **L 編號沿用講義**；沒有講義的章自己編，並在章首註明「本精華自編」。
- 版面依序是：
  1. 依因果分成幾個閘門，每個閘門有一句話說明。
  2. 閘門蛇形排列，箭頭順著因果走。
  3. 最下面是反噬帶，放副作用、抗藥、回授。
  4. 需要時加病人條件欄。
- 藥名是可以點的小標籤，分三種：
  - 本章有卡：綠色，點了跳到卡。
  - 屬於別章的高頻藥：灰色，標排名。
  - 其他：灰色。
- 虛線標籤代表病因或條件。

## 3. 結構地形圖

- **一族共用一把鑰匙**：共同骨架，用 SMARTS 標出來。
- 每個節點寫三件事：改了哪裡、換到什麼、付出什麼代價。
- 箭頭寫「改了哪個位置」。
- 每族結尾一段讀法，用 1–3 句講清這族的結構與活性關係。
- **官能基與骨架一律寫英文**，例如 aryloxypropanolamine、4-anilinoquinazoline、β-lactam。

## 4. 向量卡（每顆高頻藥一張）

- **右欄**：本體一句（配封閉動詞）→ 投影列（分組｜治／價／性｜語境 → 結果）→ 孤點 → #標籤。
- **左欄**：
  - 結構圖，鑰匙部位上色。
  - 生理 pH 下的電荷。
  - logP 刻度條。
  - t½ 對數尺，從秒到月。
  - INN 字根框：字根 → 機轉 → 母核（英文）。
  - 國考紀錄，標出考過的年份。
- **右上**：大循環位置，可以點回對應的 L；下面一行是家族骨架（英文）。
- **封閉動詞表**，共 14 個：放大、回彈、搶位、組裝、煞車、儲存、外漏、載運、轉換、遮蔽、攔截、清除、冒充、破壞。只准用這 14 個，跨章才比得起來。
- **#標籤**：跨章的共同現象（例如 #零階動力學、#弱鹼困在酸、#前驅藥切殼）。每個標籤有反查頁。

## 5. 全部超連結

- 會連結的有：
  - 藥名 → 卡。
  - 卡 → L。
  - 字根 → 字根表。
  - 標籤 → 反查頁。
  - 每頁左上「← 目錄」。
  - PDF 書籤。
- 每章頁序：
  1. 目錄＋圖例
  2. ⓪ 門派擴散記憶圖（記憶用；由內而外）
  3. ⓪→① 位置對照（門派各在大循環的哪一格）
  4. ① 大循環
  5. 結構圖
  6. 字根
  7. 卡
  8. 標籤
  9. 最後接上舊版精華，方便對答案
- 產生時自動檢查連結，**0 斷才算完成**。

## 6. 資料紀律

- **考過的年份從題庫自動比對，不手寫。** 只算題幹、正解或考點句有點名的題，選項裡的干擾項不算。
- **結構驗證**：SMILES 要和資料庫的分子式一致，鑰匙 SMARTS 要真的對到；鹽型要中和，互變異構要修正。
- **版面自動檢查**：文字不能出界、不能跨出框、不能互相重疊，結構圖不能出框。
- 每批章節做完就 commit、push。

## 7. 文字規則

- 繁體中文；短句；一句一件事。
- 不用「可推比例」「壓縮率」這類詞。
- 「考過」只在題庫真的有時才寫。

## 8. 套到藥物分析的建議對應（請依該科講義調整）

| 藥理藥化 | 藥物分析可對應成 |
|---|---|
| 一顆藥 | 一個分析方法、儀器或藥典檢驗項目 |
| 本體 | 量到哪一種物理化學性質 → 怎麼變成訊號 → 怎麼換算成量 |
| 治／價／性 | 適用對象（樣品、官能基）／限制、干擾、誤差來源／操作條件（波長、流動相、pH、溫度） |
| 大循環 L | 從樣品到數據：取樣 → 前處理（萃取、衍生化）→ 分離 → 偵測 → 定量（校正）→ 驗證（專一性、線性、準確、精密、LOD、LOQ） |
| 結構地形圖 | 「官能基 → 可用方法」對照：chromophore → UV-Vis；ionizable → titration、CE；volatile → GC；fluorophore → fluorescence；chiral → chiral column、polarimetry |
| 封閉動詞表 | 改成分析動作的封閉集，建議 12–14 個（例：分配、吸附、吸收、放射、散射、氧化還原、酸鹼中和、錯合、沉澱、衍生化、校正、分解），只准用這幾個 |
| 高頻 250 藥 | 高頻方法與檢驗項目（依 16 年題庫的出現次數排序） |
| 反噬帶 | 干擾、基質效應、系統誤差、儀器失真 |
