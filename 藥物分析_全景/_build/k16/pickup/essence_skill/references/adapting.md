# 套到其他科目

規則不變：先寫本體（上游原因）、投影從本體長出來；理解（①）和記憶（⓪）分開；⓪ 的門派＝① 的閘門；每類一列；只寫 Δ；考 n 由題庫算；全部超連結。
變的只有「單位」是什麼、「外觀」看什麼、「骨架」是什麼。

## 通用對應

| 藥理藥化 | 其他科目先問自己 |
|---|---|
| 一顆藥 | 這科的最小可考單位是什麼？（方法、劑型、生藥、法條、檢驗項目） |
| 本體 | 這個單位「做了什麼 → 因此發生什麼」的那一句 |
| 治／價／性 | 用途／限制與代價／性質與條件 |
| 大循環 L | 這科的主流程（從輸入到輸出的因果鏈） |
| 門派 | 主流程上的閘門（同一個動作、同一個旋鈕的一群單位） |
| 看到（INN 字根） | 名稱裡的固定詞根、代號、縮寫規則 |
| 摸到（骨架） | 這類單位共同的物理或化學結構（官能基、原理、裝置構造） |
| 組成 Δ | 同類之間只差哪一個維度 |
| 考 n | 16 年題庫裡被點名的次數 |
| 連動【章】 | 同一個原理在別章或別科出現的地方 |

## 藥物分析（示範對應，內容請依該科講義核對）

| 藥理藥化 | 藥物分析 |
|---|---|
| 一顆藥 | 一個分析方法、儀器或藥典檢驗項目 |
| 本體 | 量到哪一種物理化學性質 → 怎麼變成訊號 → 怎麼換算成量 |
| 治／價／性 | 適用對象（樣品、官能基）／限制、干擾、誤差來源／操作條件（波長、流動相、pH、溫度） |
| 大循環 L | 取樣 → 前處理（萃取、衍生化）→ 分離 → 偵測 → 定量（校正）→ 驗證（專一性、線性、準確、精密、LOD、LOQ） |
| 結構地形圖 | 「官能基 → 可用方法」：chromophore → UV-Vis；ionizable → titration、CE；volatile → GC；fluorophore → fluorescence；chiral → chiral column、polarimetry |
| 封閉動詞 | 分配、吸附、吸收、放射、散射、氧化還原、酸鹼中和、錯合、沉澱、衍生化、校正、分解（12–14 個，只准用這幾個） |
| 反噬帶 | 干擾、基質效應、系統誤差、儀器失真 |

⓪ 範例（層次示意）：
- 中心「把分子變成數字」，副標「性質 → 訊號 → 量｜選方法先看分子帶什麼把手」。
- 門派：分離派（層析）、看光派（光譜）、數質子派（滴定）、秤重派（重量分析）。
- 分離派 → 分支「逆相 HPLC」→ 類別「C18 逆相」「離子對」「胺基拖尾的對策」各一列。
  - 看到：USP 管柱代號（L1＝C18、L7＝C8…）。
  - 摸到：固定相化學（octadecylsilane、end-capped silica）。
  - Δ：比較軸「同一個分配原理；差在流動相 pH 與添加劑」。

## 藥劑學

- 單位：劑型、賦形劑、製程、釋放機制。
- 主流程：原料性質 → 處方設計 → 製程 → 品質 → 體內釋放與吸收。
- 門派例：增溶派、控釋派、穩定派、無菌派。
- 摸到：賦形劑的化學結構或劑型構造（matrix、reservoir、osmotic pump）。

## 生藥、中藥

- 單位：生藥、有效成分。
- 主流程：基原 → 有效成分 → 機轉 → 交互作用。
- 門派例：依成分骨架分（alkaloid、glycoside、terpenoid、phenolic）。
- 看到：學名、科名的固定詞尾；摸到：成分骨架（英文）。

## 選中心比喻的三個條件

1. 看得見、摸得到（浴缸、工廠、天平、開關、四站），不要抽象名詞。
2. 能把這章所有閘門串起來；每個門派都能說成比喻裡的一個部件。
3. 比喻有破洞時寫進 ⚠ 比喻失效提醒，不要硬拗。
