# ⓪ 門派擴散記憶圖與 ⓪→① 位置對照：格式與規則

## 為什麼要這兩頁

- ① 大循環用「因果順序」排，適合理解，但不適合一眼記住一章有哪些藥。
- ⓪ 用「由內而外」排：中心比喻 → 門派 → 分支 → 每類藥一列（外觀、組成）。
- 兩種切法不同，所以多一頁 ⓪→① 位置對照：把 ① 縮小重畫，每條 L 只標門派，讓讀者知道兩頁怎麼對上。

## ⓪ 的五層（由內而外）

| 層 | 內容 | 對應使用者的「枕頭」比喻 |
|---|---|---|
| 中心 | 這章的物理比喻（一個圓），加一行副標 | 枕頭本身 |
| 門派 | ① 的閘門；色塊，寫名稱、一句標語、L 列表 | 分類 |
| 分支 | 門派底下的功能次分流；寫名稱、一句提示、可點的 `➔ Lx` | 次分類 |
| 外觀 | 每類一個框：類別名稱、看到（字根）、摸到（英文骨架＋結構圖） | 外：顏色（看到）、形狀（摸到） |
| 組成 Δ | 每類一個框：比較軸、每顆藥一行 Δ、考 n、連動 | 內：成分 A、B、C 與比例 |

## 中心比喻怎麼選

- 一個看得見、摸得到的物理系統，能把整章的閘門串起來。
- 藥理藥化的例子：
  - 糖尿病「血糖浴缸水位」（流入、抽水、溢流）
  - 甲狀腺「工廠＋倉庫」
  - 利尿劑「腎元四站」
  - 鴉片「μ 一個開關」
  - 抗凝血「止血天平」
  - 抗生素「人沒有的零件」
  - 抗癌藥「分裂快的工廠」
- 副標寫成「結構一句｜關鍵規則一句」，例如「流入 − 流出 ＝ 水位｜HbA1c ≈ 三個月平均水位」。
- 比喻有失效的地方要寫在頁尾的 ⚠ 比喻失效提醒，例如某藥同時跨兩個門派。

## 門派、分支、類別的切法

1. **門派＝① 的閘門**。名稱用白話，可以加「｜」分兩行，例如「抽水馬達派｜給電」。
2. **分支掛 L**：分支的 L 列表就是它在 ① 的位置；點了跳回 ①。
3. **一個分支底下有幾類，就拆幾列**，每類自己一個外觀框、一個組成框。
   - 例：「直接逼 β 細胞放電」拆成 SU 類、glinide 類。
   - 例：「水位太低」拆成直接補糖、升糖激素、K-ATP 開放劑、somatostatin 類似物。
   - 同一類裡的不同世代或劑型不拆（例：胰島素速效、長效是同一類的 Δ）。
4. **類別可以只掛分支 L 的一部分**（例：amylin 類似物只在 L8），位置對照頁就只在那幾條 L 列出它。
5. 每類至少一顆藥。

## 外觀框

- **最上面寫類別名稱**：「SU 類（sulfonylurea）」「α-glucosidase 抑制劑」「GLP-1 RA（針劑為主）」。
- **看到**：INN 字根，橘色膠囊。
  - 只用字根資料庫裡真的有的字根，不自創。
  - 沒有共同字根就顯示「（沒有共同字根）」。
- **摸到**：
  - 英文骨架名稱（綠字），例如 `aryl–SO2–NH–CO–NH–R`、`4-anilinoquinazoline`、`C-aryl glucoside`。
  - 真的畫出結構（代表藥的 SMILES），鑰匙部位用 SMARTS 上色。
  - 下方一行灰字：這個骨架為什麼長這樣（一句結構與活性關係）。
  - 胜肽、蛋白、無機物不畫結構，只寫英文描述。

## 組成 Δ 框

- 標題列：「組成 Δ（考 n＝16 年被點名次數）」。
- **比較軸**（粗體、門派色）：同類之間差在哪一個維度。例如：
  - 「para 位決定代謝快慢；第二代掛大 lipophilic tail → 效價 ×100」
  - 「同一個 C-glucoside；差在 SGLT2 選擇性與心腎證據」
  - 獨門一支就寫「獨門一支，不用比 Δ」。
- **每顆藥一行**：藥丸＋考 n 章＋Δ。
  - Δ 用「｜」分段，每段一行。
  - 以 `!` 開頭的段落畫紅字，代表致命代價。
  - 藥丸前加 `~`＝不是藥卡（類別、共同代價、內生物、病因）→ 虛線藥丸。
  - 共同代價寫成一行 `~XX 共同`。
- **考 n**：由題庫自動比對（只算題幹、正解、考點句），3 次以上實心藍章。
- **連動框**（紫色虛線）：「連動【章名】＋一句」，同一個標的在別章出現時才加。

## 顏色

| 用途 | 顏色 |
|---|---|
| 分支紅框 | 該章定義的高風險（例：低血糖、致命代價） |
| 分支綠框 | 相對安全、首選 |
| 看到（字根） | 橘 |
| 摸到（骨架） | 綠 |
| 連動 | 紫 |
| 考 n | 藍 |
| 門派色塊 | 沿用 ① 閘門的顏色 |

每章在頁首圖例寫清楚紅框、綠框各代表什麼。

## 版面

- 橫式大頁，中心圓在正中，門派向左右兩側展開，每條連線用貝茲曲線。
- 左右分配自動找讓兩側高度最接近的組合（保持原順序）。
- 每排由外到內：組成 Δ ← 外觀 ← 分支 ← 門派 ← 中心（左側是鏡像）。
- 文字一律自動換行：分支的 `➔ L` 列表、門派標語、門派 L 列表都要換行；門派方塊依內容長高。
- 右上角放「➔ 看各門派在 ① 大循環的哪個位置（位置對照）」連結。
- 頁尾兩行：
  - 分工：⓪ 記憶、① 理解、② 單一藥細節。
  - ⚠ 比喻失效提醒。

## ⓪→① 位置對照頁

- 閘門位置、順序、顏色和 ① 一樣（蛇形，同樣的欄數），反噬帶、支線放在下面。
- 沒有 L 的閘門（例：純文字的反噬帶、病人條件）不畫。
- 每條 L 一列：
  - 左邊「➔ Lx」＋L 名稱（點了去 ①）。
  - 右邊門派色塊（點了回 ⓪）＋分支名稱＋（掛在這條 L 的類別名稱）。
  - 沒有門派的 L：灰色虛線框「不屬任何門派（機轉、代價或藥物命運：看 ① 推導）」。
- 頂端一排門派圖例（可點回 ⓪），底端一行讀法說明。

- `SC(門派, 標語, 色, 分支…)`；門派的 L 列表自動由分支合併。
- `BR(分支, 提示, [L…], 類別…, risk="red"/"grn"/None)`
- `KL(類別名, [只在這幾條 L]|None, [字根…], T(...), 比較軸, [(藥, Δ)…], link=(章名, 一句))`
- `T(英文骨架, smiles, 鑰匙 SMARTS, 一句說明)`；沒有 smiles 時只寫英文。
- `RAD(中心, 中心副標, [門派…], caveat, legend)`；不給左右時自動分配。
