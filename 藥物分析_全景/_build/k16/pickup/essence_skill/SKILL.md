# 精華講義製作法（essence-handout）

這份 skill 是藥理藥化精華 v2.0 的製作規則，寫給其他科目的對話照著做。
**材料前提**：16 年國考題庫（已拆成考點）＋該科的大小循環講義（L 編號）。沒有講義的章自己編 L，並在章首註明「本精華自編」。

## 一句話

**理解和記憶拆成兩件事。**
- 理解交給 ① 大循環：從第一性原理推出因果鏈，藥（或方法）掛在鏈上。
- 記憶交給 ⓪ 門派擴散圖：由內而外，看到什麼、摸到什麼、同類之間差在哪。
- 兩頁用 `➔ Lx` 互相連結：記不起來就點回 ① 重推，不硬背。

## 地基：pick up 原則（先讀這段）

`pick up` 有撿起、接收訊號、學會、接人四個意思，但只有一個本體：「一個東西從他處移到我處」。
講義的工作就是找出那個本體，先寫本體，再讓投影從本體長出來。

1. **向量走在例子前面**：先寫一句本體，再列投影。
2. **本體必須是真正的上游原因**：寫得太下游，投影會推錯。
3. **療效和副作用放在同一組投影**：用顏色分（治＝綠、價＝紅、性＝藍灰），不拆成兩欄。
4. **一個單位最多 3 個引擎**：真的有兩三個獨立原因，就分成幾個本體。
5. **推不出來的老實放孤點**：不編假因果。
6. **分清機轉橋和記憶鉤**：記憶鉤要標明不能拿來推題。

**檢查本體的三個測試**：
- 遮住測試：遮住投影，從本體自己推得出來嗎？
- 上游測試：某條投影需要另一個不相干的原因嗎？
- 反向測試：拿一題題幹，能一路追回本體嗎？

完整說明與實例見 `references/philosophy.md`。

## ⓪ 門派擴散記憶圖：九條硬規則

1. **門派＝① 的閘門**（一對一或一對少數），不另起分類，避免兩張圖切法不同而迷路。
2. **一個分支底下有幾類，就拆幾列**。例：「進食聰明擴音器」底下的 DPP-4 抑制劑、GLP-1 RA 各自一列，不混在一起。
3. **外觀框最上面寫類別名稱**，例如「SU 類（sulfonylurea）」「GLP-1 RA（針劑為主）」。
4. **外觀＝看到＋摸到**：
   - 看到＝INN 字根（從字根資料庫取，不自創）。
   - 摸到＝英文骨架名稱，加上真的畫出來的結構圖，鑰匙部位上色。
5. **組成只寫 Δ**：先寫比較軸（同類差在哪一個維度），每顆藥只寫跟同類不同的那一點；致命代價用紅字（`!` 開頭）。
6. **不重抄機轉**：機轉留在 ①，⓪ 只放 `➔ Lx` 連結。
7. **比例＝考 n**：每顆藥旁標 16 年題庫被點名次數，3 次以上用實心藍章。
8. **跨章連動**：同一個標的在別章出現，就用紫色虛線框寫「連動【章名】＋一句」。
9. **骨架、官能基、胺基酸位置一律英文**；其他用繁體中文短句。

格式、色碼、資料結構與完整範例見 `references/radial.md`。

## 工作流程（每章）

1. **讀 ①**：列出這章的閘門、每條 L、掛了哪些藥或方法、結構族。
2. **寫 ⓪ spec**：門派（＝閘門）→ 分支（掛 L）→ 每類一列（類別名、字根、骨架、比較軸、Δ、連動）。
3. **自動檢查**：⓪ 的 L 都在 ①、類別的 L 是分支的子集、SMILES 能解析、鑰匙 SMARTS 對得到、每類至少一個藥。
4. **產生 PDF**：超連結 0 斷才算完成；版面檢查（文字不出界、不重疊）。
5. **看一眼渲染圖**：門派方塊、分支框、外觀框有沒有溢出；左右兩側高度是否平衡。
6. **每批 commit、push。**

QA 清單與常見錯誤見 `references/workflow.md`。

## 套到其他科目

見 `references/adapting.md`：藥物分析、藥劑、生藥等科目的對應表，以及「中心比喻 → 門派 → 分支 → 類別」怎麼選。

## 文字規則

- 繁體中文；短句；一句一件事。
- 不用「可推比例」「壓縮率」這類詞。
- 「考過」只在題庫真的有時才寫，次數一律由題庫自動比對，不手寫。
- 只算題幹、正解或考點句有點名的題；選項裡的干擾項不算。

## 本 repo 的實作（要沿用程式時看）

- 產生器：`全景網頁/build/essence2/`
  - `radial.py`：⓪ 與 ⓪→① 的排版。
  - `common.py`：①②③④⑤ 的排版、封閉動詞表、色碼。
  - `build_ch.py`：一章的頁序、目錄、書籤、超連結組裝。
  - `check_fams.py`：結構與 ⓪ 的自動檢查。
  - `ch/_h.py`：spec 小工具 `L`、`G`、`N`、`SC`、`BR`、`KL`、`T`、`RAD`。
  - `ch/<章>.py`：每章 spec。糖尿病 `dm.py` 是第一個試作，可當範本。
- 指令：`cd 全景網頁/build && python3 -m essence2.check_fams <章> && python3 -m essence2.build_ch <章>`
- 核心思想全文：`全景網頁/精華v2_核心思想_給其他科目沿用.md`
