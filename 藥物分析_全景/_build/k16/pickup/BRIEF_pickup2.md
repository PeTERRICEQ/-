## 二、試做學到的做法（照做）
1. **先測示範句或試算句，再往上提。** 非水滴定的示範句單獨只推得出 16/43，往上提成「質子只往更想要它的地方走，水會搶」後推得出 40/43；HPLC 的「越油留越久」推不出正相、離子交換、SEC、手性、HILIC，提成「越像固定相留越久，像由固定相定義」後全收回。p3 要寫「改過的本體」：v0 → v1 → 本版，每次改了什麼、推得出的題從幾題變幾題。
2. **引擎數判定。** 兩個本體若有很多題要合用（約 ≥ 1/4），通常是同一個本體落在兩個語境 → 合成一個。真正獨立的原因（換掉一個不影響另一個，例如換偵測器 tR 不變）才分開。每章 p1 或 p3 寫一個「引擎數判定」方塊說明理由。
3. **每個學習單位最多 3 個引擎**；合併檔（如 IR 與 Raman、折光與旋光）每一章各自算。共用引擎不算在 3 個裡，但一章最多掛 2 個共用。
4. **共用引擎用下面的標準句**（vec 照抄，可在後面加一句「在本章：…」），L 寫「共用」，動詞照下表：
   - 分配（動詞 分配）：分子在兩相之間來回分配 → 待在哪一相的比例由像不像決定 → 越像固定相（或萃取相）待越久
   - 解離（動詞 解離）：pH 對 pKa 決定分子帶不帶電 → pH 每離 pKa 一個單位，兩型比例差 10 倍 → 帶電型像水、中性型像油
   - 把柄（動詞依偵測原理）：探針只量一種物理量 → 分子在這個量上要和背景不同才看得到 → 擁有這個量的分子越少，選擇性、靈敏度越高，通用性越低
   - 能隙（動詞 吸收）：光子能量 E＝hν 要剛好對上某個能階差才被吸收 → 能階差由結構決定 → 不同波段讀不同的能階（核自旋、轉動、振動、價電子、內層電子）
   - 計量（動詞 計量）：讀數和量成正比 → 比例係數要用同條件的標準品或反應式定 → 讀數比＝量比，再乘回稀釋
   - 擴散（動詞 擴散）：同一種分子走的路徑不同、進出固定相有延遲、自己往前後散開 → 峰變寬 → 顆粒越小 A、C 項越小，B 項只看待多久
   若本章需要的共用本體不在表上，就寫成本章引擎，並在回報裡提出。
5. **封閉動詞 15 個**（多了「折射」），只能用 lib.py 的 `VERBS`。
6. **零件卡**依 16 年被考次數排序（關鍵字計數後人工校正，並在 p2 副標註明是計數）；卡太多時延續到 p3 左上，保持字級 ≥ 12.5px。每張卡的 vec 要寫出它是哪個引擎的落地（例如「（E2 的落地）」）。
7. **p3** 固定有：遮住測試結果表（每個引擎 Y／2／N）、推不出來的題與原因、孤點清單（標考次）、3 個反向測試、舊題找本體與新題驗收（100–107 寫本體，108–115 可推比例）、改過的本體（v0→v1→本版）。
8. **所有中間成果直接寫進 repo 路徑**（spec、mask json），不要只放 /tmp；容器可能重啟。
9. 遮住測試檔：每個章代碼一個檔 `/home/user/-/藥物分析_全景/_build/k16/pickup/<章代碼>_mask.json`（例如 ir_mask.json、ram_mask.json）；只測 ch[0] 屬於該章的題。目標 Y＋2 ≥ 90%（題數 < 15 的小章 ≥ 85%）。
10. spec 檔名：`/home/user/-/藥物分析_全景/_build/essence/specs/<key>2.py`；`SPEC = dict(file="<與 v1.1 相同>", ver="v2_0", append="<與 v1.1 相同>", keys=[...], name=..., field=...（傳統分析章要給 "cnt"）, p1, p2, p3)`。v1.1 的 spec 在 `specs/<key>.py`，可參考內容，但不要改它。
11. 不要改 lib.py、print.js、cover.py、別人的 spec，不要 git commit。需要產生器新功能就在回報裡說。
